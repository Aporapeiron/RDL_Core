# 04_Examples

## 0. 位置づけ

`04_Examples` は、RDL Core の基底仮設と操作仕様だけを使って、実際に対象を一巡させるための使用例集である。

ここでの目的は、個別問題に最終回答を与えることではない。

目的は、RDL の基本操作

```text
B設定
↓
SILN化
↓
SILN展開
↓
検査と選別
↓
再構成
↓
M_B'
↓
ξ保持
```

を、具体的な題材で動かして見せることである。

---

## 1. Examples の基本姿勢

RDL は、いきなり

```text
Xとは何か
```

という本質問いへ進まない。

まず、

```text
何がXとして観測・判定されているか
どの条件でその判定が維持されるか
どの条件で破断するか
誰の B / M_B でそう見えるか
```

へ展開する。

Examples は、この問いの変換を実際に示す。

---

## 2. 共通操作

各Exampleでは、原則として次の順序を使う。

### 2.1 問いの変換

```text
本質問い
↓
観測・判定条件の問い
```

### 2.2 現在の M_B

観測者側が、すでにどのような認識構造を保持しているかを見る。

### 2.3 B の設定

今回、どの関係を操作対象として切り出すかを定める。

### 2.4 SILN化

対象を「答え」や「真理」として固定せず、操作対象として切り出す。

### 2.5 SILN展開

硬いラベルを、複数の関係軸へ展開する。

### 2.6 検査と選別

関係軸を変化・破断させ、何が判定へ寄与しているかを見る。

### 2.7 再構成

検査後に残った関係を、現在より操作可能な `M_B'` として血肉化する。

### 2.8 ξ保持

未回収関係、判定差、未検査条件、定量化できていない部分を `ξ` として残す。

---

## 3. Examples がしないこと

Examples は、次を目的としない。

```text
・哲学問題の最終解決
・一意の正解の提示
・RDL用語による言い換えだけの説明
・すべての関係軸の網羅
・局所モデルの即時な普遍化
```

Example 内で得られた再構成は、その題材と設定した `B` のもとで現在有効な仮設として扱う。

---

## 4. 現在の Examples

現在、`Paradoxes/` には次の3例がある。

| Example | 問いの変換 | 主に見る構造 |
|---|---|---|
| テセウスの船 | 何を「同じ」と感じるか | 関係ネットワークの維持・破断 |
| 砂山のパラドックス | 何を「あるカテゴリ」と感じるか | 連続入力 → `F` → `θ_eff` → 離散判定 |
| 中国語の部屋 | 何を「理解」と感じるか | `F = interp(M_B, EFP)` と観測・学習 |

3本は同じ操作型を使うが、照らす側面が異なる。

---

## 5. 3本の補完関係

```text
テセウスの船
→ 同一性の維持・破断
→ 対象側の時間変化

砂山
→ カテゴリの立ち上がり
→ 局所有効閾値 θ_eff

中国語の部屋
→ 理解判定の形成
→ F = interp(M_B, EFP)
→ 対象側・観測者側双方の M_B 更新
```

この3例を通すことで、RDL Core の主要な操作要素を異なる角度から確認できる。

---

## 6. 推奨読順

初めて Examples を読む場合は、次の順序を推奨する。

```text
1. テセウスの船
   ↓
   「同じ」という日常判定を分解する

2. 砂山のパラドックス
   ↓
   連続変化からカテゴリ境界が立ち上がる構造を見る

3. 中国語の部屋
   ↓
   観測された偏りを M_B が F として読む日常構造を見る
```

この順序は、

```text
対象の同一性
→ 判定境界
→ 観測と解釈そのもの
```

へ徐々に基底側へ降りていく読み方でもある。

---

## 7. 一文圧縮

> **Examples は、RDL の基底仮設を説明する場所ではなく、対象を B で切り出し、SILNとして展開・検査し、使える M_B' へ再構成して ξ を残すまでを、実際に動かして示す場所である。**
