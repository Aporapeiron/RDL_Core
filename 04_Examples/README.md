# 04_Examples

## 0. 位置づけ

`04_Examples` は、RDL Core の基底措定と操作仕様だけを使って、実際に対象を一巡させるための使用例集である。

ここでの目的は、個別問題に最終回答を与えることではない。

目的は、RDL の基本操作

```text
問いの変換
↓
対象となる SILN / 現在の M_B を確認
↓
用途・問いに応じて B を設定
↓
RIB_B = Section_B({RIB_i}) を取得・構成
↓
F = interp(M_B, RIB_B)
↓
SILN展開
↓
検査と選別
↓
再構成
↓
M_B'
↓
ξ保持
```

を、具体的な題材で動かして見せることである。

SILN は `B` によって初めて生成される「食材」ではない。RDL が扱う基底構造であり、Example ではそのうち何を今回の対象として扱うかを明示し、`B` によって構造側 `M_B` と相互作用側 `RIB_B` の有限断面を形成する。

---

## 1. Examples の基本姿勢

RDL は、いきなり

```text
Xとは何か
```

という本質問いへ進まない。

まず、

```text
何がXとして観測・判定されているか
どの条件でその判定が維持されるか
どの条件で破断するか
誰の B / M_B でそう見えるか
どの RIB_B がその判定形成に関与しているか
```

へ展開する。

Examples は、この問いの変換を実際に示す。

---

## 2. 共通操作

各Exampleでは、原則として次の順序を使う。

### 2.1 問いの変換

```text
本質問い
↓
観測・判定条件の問い
```

### 2.2 対象となる SILN と現在の M_B

今回どの SILN を対象化するのかを明示し、観測者側がすでにどのような有限関係拘束構造 `M_B` を保持しているかを見る。

### 2.3 B の設定

今回の用途・問い・尺度・観測条件を有限境界 `B` として定める。

### 2.4 RIB_B の取得・構成

対象・環境・観測者・他 SILN との相互作用群 `{RIB_i}` から、現在の `B` で扱う有限作用断面を切り出す。

```text
RIB_B = Section_B({RIB_i})
```

### 2.5 F の形成

現在の自己側有限構造 `M_B` が `RIB_B` を解釈し、作用解釈 `F` を形成する。

```text
F = interp(M_B, RIB_B)
```

### 2.6 SILN展開

対象化した SILN と観測された `RIB_B / F` を、複数の関係軸・候補構造へ展開する。

### 2.7 検査と選別

関係軸や相互作用条件を変化・破断させ、何が判定や構造維持へ寄与しているかを見る。

### 2.8 再構成

検査後に残った関係を、現在より操作可能な `M_B'` として血肉化する。

### 2.9 ξ保持

未回収関係、判定差、未検査条件、定量化できていない部分を `ξ` として残す。

---

## 3. Examples がしないこと

Examples は、次を目的としない。

```text
・哲学問題の最終解決
・一意の正解の提示
・RDL用語による言い換えだけの説明
・すべての関係軸や RIB の網羅
・局所モデルの即時な普遍化
```

Example 内で得られた再構成は、その題材と設定した `B` のもとで現在有効な仮設として扱う。

## 4. 現在の Examples

現在、`Paradoxes/` には次の4例がある。

| Example | 問いの変換 | 主に見る構造 |
|---|---|---|
| テセウスの船 | 何を「同じ」と感じるか | 関係ネットワークの維持・破断 |
| 砂山のパラドックス | 何を「あるカテゴリ」と感じるか | `RIB_B → F → θ_eff` と離散判定 |
| 中国語の部屋 | 何を「理解」と感じるか | `F = interp(M_B, RIB_B)` と観測・学習 |
| 記号接地問題 | 何を「意味が接地している」と感じるか | 記号・身体・行為・環境の関係網 |

4本は同じ操作型を使うが、照らす側面が異なる。

また、`Occult/` には次の例がある。

| Example | 問いの変換 | 主に見る構造 |
|---|---|---|
| お化け生成モデル | 何を「お化け」「何かいる」と感じるか | 高不確実・高危険環境における `RIB_B / F`、警戒モード、`H` 蓄積、文化的 SILN |

---

## 5. Paradoxes 4本の補完関係

```text
テセウスの船
→ 同一性の維持・破断
→ 対象側の時間変化

砂山
→ カテゴリの立ち上がり
→ RIB_B / F / 局所有効閾値 θ_eff

中国語の部屋
→ 理解判定の形成
→ F = interp(M_B, RIB_B)
→ 対象側・観測者側双方の M_B 更新

記号接地問題
→ 意味接地判定の形成
→ 記号・身体・行為・環境の関係網
→ 終端的な接地点要求の破断
```

この4例を通すことで、RDL Core の主要な操作要素を異なる角度から確認できる。

---

## 6. 推奨読順

初めて Examples を読む場合は、次の順序を推奨する。

```text
1. テセウスの船
   ↓
   「同じ」という日常判定を分解する

2. 砂山のパラドックス
   ↓
   連続変化からカテゴリ境界が立ち上がる構造を見る

3. 中国語の部屋
   ↓
   RIB_B を M_B が F として読む日常構造を見る

4. 記号接地問題
   ↓
   意味接地判定を支える関係網を見る

5. お化け生成モデル
   ↓
   「見えない主体」や「気配」が立ち上がる構造を見る
```

この順序は、

```text
対象の同一性
→ 判定境界
→ 観測と解釈そのもの
→ 意味判定を支える関係網
→ 認識・感情・社会的反復
```

へ徐々に基底側へ降りていく読み方でもある。

## 7. 一文圧縮

> **Examples は、RDL の基底措定を説明する場所ではなく、SILN を用途・問いのもとで対象化し、B によって M_B / RIB_B の有限断面を取り、F を形成し、展開・検査・再構成して ξ を残すまでを、実際に動かして示す場所である。**
