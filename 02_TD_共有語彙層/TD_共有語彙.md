## ■ 0. 位置づけ

本文書は、関係力学言語（RDL）の全層（T0 基盤層、T1 SILN操作層、T2 代謝機構層、T3 応用層）で共通して使用される**記号・基底量・中核概念・補助表記**を定義する中核辞書（DICT）である。

T-D 本体は、RDL 内部で使用する語彙の**最小定義と身分**を保持する。具体的な数式・更新則・標準動態モデルは T0 SPEC に属し、本辞書では必要な場合のみ**標準表記・参照例**として区別して示す。

自然言語上の概念を RDL の関係記述へ対応づける翻訳辞書は、語彙増加による本体肥大化を避けるため、別冊 **`TD_自然言語概念のRDL的翻訳.md`** に分離して保持する。

### 0.1 認識論的前提：便利語彙としての境界提示（自己例外化の禁止）

本文書および RDL が提示する記号群（`SILN`, $B$, $M_B$, $\xi$, `RIB`, `RIB_B`, $F$, $E$, $H$, $\theta$ 等）は、**「世界そのものの絶対的真理」や「客観的実体の名辞」として措定されたものではない**。

RDL が基底構造として扱うのは **SILN** である。SILN は孤立した静的実体ではなく、非線形関係ネットワーク上で、重力、大気圧、接触、熱、光、音、情報、社会規範、他の SILN からの応答など、性質・尺度・方向の異なる複数の相互作用束に関与しながら構造を保持・変化させる。

これらの相互作用束を一般に **`RIB`（Relational Interaction Bundle）** と呼ぶ。`RIB` は外界から独立に飛来する粒子やパケットを意味せず、関係ネットワーク上で成立する相互作用束の一般記号である。

RDL が通常直接操作するのは、すべての RIB や関係ネットワーク全体ではない。用途・問いに応じて有限境界 $B$ を引き、構造側では SILN を自己側有限構造 $M_B$ として、相互作用側では一つ以上の RIB を有限作用断面 `RIB_B` として扱う。

したがって、**RDL 語彙体系自身もまた SILN として対象化可能であり、有限境界 $B_{\text{RDL}}$ のもとで自己側有限構造 $M_{B,\text{RDL}}$ として保持される**。本辞書の外部には常に未回収関係 $\xi_{\text{RDL}}$ が残存し、より生存可能で頑健な切り分け方が見出されれば、語彙そのものが再編・更新されうる（B5 自己例外化禁止 / Aporapeiron）。

### 1.1 標準表記・標準モデル参照

以下は T0 SPEC v2.3 で使用される標準形の例であり、上記語彙の唯一の定義ではない。

```text
RIB_B(t)     = Section_B({RIB_i(t)})
F(t)         = interp(M_B, RIB_B(t))

RIB_B(t+Δ)   = Section_B({RIB_i(t+Δ)})
F'(t+Δ)      = interp(M_B, RIB_B(t+Δ))

E(t+Δ)       = Δ(F, F')

H = ||H_vec||
H_vec = P_unresolved(δM_B(t))

θ_eff(t) = θ + g(ξ(t))
dM_B/dt = f(M_B, E, ξ)
```

$\mathcal{K}$ の具体形を含む局所近似式も Standard Model 側に属し、T-D の最小定義には含めない。

### 2.1 SILN・$M_B$・RIB・`RIB_B`・$\xi$・Aporapeiron の区別

```text
SILN
= RDL が扱う有限構造の基本形

M_B
= SILN を、用途・問いに応じた有限境界 B のもとで
  自己側・解釈側として保持した構造断面

RIB
= 非線形関係ネットワーク上で成立する相互作用束

RIB_B
= 一つ以上の RIB を B によって有限に切り出した作用断面

ξ
= ある有限境界 B に対して回収されない関係

Aporapeiron
= SILN と相互作用を有限化しても ξ が残り、
  構造と断面が検査・破断・再構成へ開かれ続ける非終端的な関係運動
```

`M_B` と `RIB_B` は同じ階層の実体ではなく、用途・問いに応じた有限境界 $B$ が、**構造側と相互作用側に形成する対応断面**である。SILN はそのうち「対象側だけ」に限定される概念ではない。

Aporapeiron は SILN の「外側の場所」や「こぼれた残り」を指す語ではない。また、SILN と Aporapeiron を二項対立として扱わない。
