# 拘束維持・拘束解放と、整合・跳躍の観測的定義
*T0-T1接続 / CORE / DRAFT v2.1*

---

## ■ 0. この文書の位置

本文書は、「整合」と「跳躍」を、v2.3 の基底力学

```text
SILN
RIB / RIB_B
B
M_B
F / F'
E
H
θ
M_Δ
M_B'
ξ
```

に基づき、**拘束維持および拘束解放〜再拘束という相遷移プロセスに対する観測的ラベル**として整理する。

「整合」と「跳躍」は世界そのものの存在論的性質や神秘的な現象ではない。

> **固定された有限境界 B のもとで、後続 `RIB_B` から形成された作用解釈 `F'` と、現在の `M_B` が保持する予測・解釈 `F` の差異を、既存拘束の許容内で処理できたか、あるいは拘束解放・再構成を必要としたかを読むための観測的二分である。**

---

## ■ 1. 一文定義

> **「整合」と「跳躍」は対象の基底性質ではなく、境界 $B$ を引いた後の観測的ラベルである。**  
> **後続 `RIB_B` による差異が既存 $M_B$ の拘束内で吸収され、$H < \theta$ が維持されれば「整合」。**  
> **残存不整合が保持限界を超え、$M_\Delta$ を経て再構成 $M_B'$ が必要になり、その相遷移を粗い解像度で一つの断面として読めば「跳躍」。**

---

## ■ 2. 「拘束維持」と「流れ」の正体

従来「流れに沿う」「慣性投影」と呼ばれていたものの操作的実体は、**現在の有限関係拘束構造 $M_B$ が解釈・予測・応答へ与えている拘束作用**である。

> **「流れ」＝ 現在の $M_B$ の拘束作用を時間・更新抵抗の断面として読んだもの。標準表記では $I(M_B)$。**

しかし v2.3 では、`M_B` は孤立して動くものではない。

```text
SILN
↕ 複数の RIB
↓ B
RIB_B
↓
F = interp(M_B, RIB_B)
```

という相互作用の中で、`M_B` の拘束が後続解釈を偏らせる。

したがって「流れ」は、外部から独立した入力列に対する内部慣性ではなく、**SILN が RIB 群との相互作用を続ける中で、現在の $M_B$ が後続 `RIB_B` をどう解釈しやすいかという拘束の継承**として読む。

---

## ■ 3. 力学的プロセスと観測的ラベル

標準形は次のように置ける。

```text
RIB_B(t)       = Section_B({RIB_i(t)})
F(t)           = interp(M_B, RIB_B(t))

RIB_B(t+Δ)     = Section_B({RIB_i(t+Δ)})
F'(t+Δ)        = interp(M_B, RIB_B(t+Δ))

E(t+Δ)         = Δ(F, F')
```

その後、未解消成分が `H` として残る。

```text
E（不整合）
 │
 ├─ 現 M_B の拘束内で吸収・局所解消
 │    H < θ
 │      ↓
 │   【拘束維持】
 │      ↓
 │   観測的ラベル：整合
 │
 └─ 未解消成分が残存・蓄積
      H ≥ θ
        ↓
     【保持限界突破】
        ↓
     M_Δ
     Probe / SILN展開 / 検査 / 選別
        ↓
     M_B'
     【再拘束・新安定相】
        ↓
     粗い断面では「跳躍」と読まれうる
```

### 3.1 整合

**整合**とは、差異が存在しない状態ではない。

```text
E = 0
```

を要求せず、現在の `M_B` が後続作用断面との不整合を処理し、未解消残存不整合 `H` を保持限界以下に維持できている状態を指す。

### 3.2 跳躍

**跳躍**とは、独立した基底現象ではない。

`H ≥ θ` によって既存拘束維持が破れ、`M_Δ` を経て `M_B'` へ再構成される一連の相遷移を、観測解像度が粗いために「前と後が急に変わった」と離散的に読んだラベルである。

---

## ■ 4. 整合・跳躍は基底量ではない

整合・跳躍それ自体を Core Primitive へ置かない。

基底・中核側にあるのは、

```text
SILN
RIB / RIB_B
B
M_B
ξ
F / F'
E
H
θ
M_Δ
M_B'
```

である。

整合・跳躍は、これらの動態をある `B` と観測解像度のもとで二分して読んだ**自然言語・観測ラベル**である。

---

## ■ 5. 非対称性と「跳躍」の脱神秘化

「拘束」と「解放」は静的な二項対立ではない。

```text
拘束維持
↓
保持限界突破
↓
拘束解放・再編 M_Δ
↓
再拘束 M_B'
```

再構成後の `M_B'` も有限関係拘束構造であり、完全な無拘束へ移行するわけではない。

したがって「跳躍」とは、自由状態そのものでも、未知 `ξ` が直接噴出したものでもない。

> **現在の拘束では処理できない差異が顕在化し、拘束配置の再編を必要とした過程を、粗い断面から跳躍と読む。**

`ξ` はその過程の原因名でも跳躍の別名でもない。`ξ` は有限境界によって回収されない関係であり、その一部が後続相互作用を通じて差異として顕在化することはありうるが、両者を同一視しない。

---

## ■ 6. M_B / RIB_B / ξ との対応

v2.3 では、有限境界 `B` によって、構造側と相互作用側の双方に有限断面が成立する。

| 断面 | 有限に扱うもの | 残るもの |
|---|---|---|
| 構造側 | $M_B$ | $\xi$ |
| 相互作用側 | `RIB_B` | $\xi$ |
| 動態側 | $F → E → H$ と維持 / 再編 | 未回収・未検査の関係と将来差分 |

したがって、旧来のように

```text
M_B / ξ
= 整合 / 跳躍
```

という一対一対応を置かない。

より正確には、

> **`M_B / RIB_B + ξ` という有限断面のもとで、後続差異を現拘束内で処理できるか、再編が必要かを観測したラベルが整合 / 跳躍である。**

---

## ■ 7. 連続と離散との接続

「跳躍」は観測解像度に強く依存する。

粗い断面では、

```text
M_B
↓
M_B'
```

と突然変わったように見える。

しかし解像度を上げると、

```text
H 上昇
↓
θ 付近
↓
拘束維持の不安定化
↓
M_Δ
↓
探索・検査・選別
↓
再拘束
↓
M_B'
```

という内部過程を区別できる可能性がある。

したがって、

```text
粗い ρ
→ 「跳躍」として一つの離散変化に見える

高い ρ
→ 内部相遷移を複数断面として追跡できる
```

と読むことができる。

これは「真の世界は連続である」という存在論的主張ではない。`ρ` は観測・記述解像度を表す便利記号である。

---

## ■ 8. 有効範囲（B 相対性）

同一事象でも、境界 `B` や対象化する SILN が変われば、整合／跳躍の判定は変わりうる。

```text
レベル n
→ 局所 M_B では差異を吸収
→ 整合

レベル n+1
→ 広域 M_B では保持限界突破
→ 跳躍
```

逆もありうる。

したがって、「何が跳躍したか」を記述する場合は、少なくとも

```text
誰 / 何の SILN を
どの B で
どの M_B と RIB_B を用いて
どの ρ で観測したか
```

を必要に応じて明示する。

---

## ■ 9. Core命題の締め直し

> **整合と跳躍は、固定された有限境界 $B$ のもとで、後続 `RIB_B` を現在の $M_B$ が解釈した結果生じる差異が、保持限界 $\theta$ の内部で処理されたか（拘束維持）、あるいは $H \ge \theta$ により $M_\Delta$ を経た再構成 $M_B'$ を必要としたかを、一定の観測解像度から読んだ二つのラベルである。**

---

## ■ 10. 対応表

| 項目 | 定義 |
|---|---|
| SILN | 相互作用の中で動的に保持される基底構造 |
| RIB | 関係ネットワーク上の相互作用束 |
| RIB_B | 現在の B で有限に取得された相互作用側断面 |
| M_B | 現在の B で自己側・解釈側として保持される有限関係拘束構造 |
| 流れ（一貫性） | 現在の $M_B$ が後続解釈・応答へ与える拘束作用。標準表記 $I(M_B)$ |
| 整合 | 差異が現拘束内で処理され、$H < \theta$ が維持される状態に対する観測ラベル |
| 跳躍 | $H \ge \theta$ から $M_\Delta → M_B'$ へ至る再編過程を粗い断面で読む観測ラベル |
| ξ | 有限 B で回収されない関係。跳躍の別名ではない |
| ρ | 変化・相遷移をどこまで細かく区別して読むかという解像度 |

---

## ■ 11. 一文圧縮

> **整合は「変化がない」ことではなく、後続 `RIB_B` から生じた差異を現在の `M_B` が保持限界内で処理できている状態であり、跳躍は独立した神秘的現象ではなく、保持限界突破から `M_Δ` と再構成 `M_B'` に至る相遷移を、ある B・ρ のもとで離散的に読んだラベルである。**
