## ■ 0. 位置づけ

本文書は、日常語・哲学語として用いられる**自然言語概念を、RDL の関係記述へ翻訳するための拡張可能な辞書**である。

ここでいう「翻訳」は、一般語義を廃止したり、RDL 独自語へ機械的に置換したりすることを意味しない。自然言語上の概念が、有限境界 $B$、現在の $M_B$、関係の偏り、$\xi$ 等を用いた記述では、どのような構造として現れるかを対応づける。

```text
TD_共有語彙.md
= RDL 内部語彙の最小辞書

TD_自然言語概念のRDL的翻訳.md
= 自然言語概念 → RDL 関係記述の翻訳辞書
```

本辞書に置かれる語は、原則として Core Primitive を新設するものではない。既存の RDL 語彙から自然言語概念をどう読めるかを示し、必要に応じて追加・更新する。

## ■ 1. 偏りから翻訳される概念

以下は、自然言語上の「意味・価値」等を、関係ネットワーク上に生じる偏りとして読むための最小翻訳である。

ここでいう**偏りの勾配**は、ある局所状態から後続の解釈・予測・選択・行為等がどの方向へ、どの程度生じやすくなるかを表す説明的表現であり、現段階では Core Primitive として独立させない。

| 自然言語概念 | RDL 的翻訳 |
| :--- | :--- |
| **意味** | 有限境界 $B$ のもとで対象を切り出したとき、現在の $M_B$ において立ち上がる**偏りの勾配の束**。人が「意味」と感じるものを、対象に内在する固定内容ではなく、関係ネットワーク上の複数方向への偏りとして読む。 |
| **無意味** | 「関係や偏りが絶対に存在しない」ことではなく、現在の $B / M_B$ のもとで、意味として有効に働く**偏りの勾配の束が立ち上がらない、または判定可能なまとまりを形成しない状態**。 |
| **価値** | 現在の $M_B$ に対して、接近・維持・選好・回避等の**方向と強さを持つ偏りの勾配**。対象に固定された属性ではなく、$B / M_B$ と対象との関係において立ち上がる。 |
| **意義** | 意味を構成する偏りの勾配の束のうち、現在の自己の選択・行為・更新へ有効に接続する断面。何を表すかだけでなく、**現在の $M_B$ にとって何を変えるか**として読む。 |

したがって、同じ対象でも $B$ や $M_B$ が変われば、意味の束・価値の方向や強さ・意義の有効範囲は変化しうる。

## ■ 2. 確定化しやすい概念の翻訳

RDL 運用において確定化（$\xi=0$ の主張）に陥りやすい日常語・哲学語は、次のように翻訳して扱う。

| 自然言語概念 | RDL 的翻訳 |
| :--- | :--- |
| **客観** | **間主観的再現性**（観測者非依存の絶対視点ではなく、「誰が $B$ を引いても $\xi$ から逃げられない」普遍性）。 |
| **中立・公平** | **偏りの自覚と引き直し**（偏りゼロは構造的に不能。どの $B$ で偏っているかを自覚し、固着せず引き直す）。 |
| **真理・絶対** | **$\text{ADD}\xi(\text{真理})$**（禁止せず保持するが、終端閉包されない仮設として扱う）。 |
| **安定** | **現在の $B$ のもとで差異を吸収できている状態**（$\xi=0$ を意味せず、$M_B$ が局所的な整合を維持している状態）。 |
| **破綻・失敗** | **再検査・境界更新・再構成を導く診断情報**（終端ではなく、次の有限構造へ移る契機）。 |

---

## ■ 3. 追加原則

自然言語概念を追加するときは、少なくとも次を区別する。

- その語を RDL の新しい基底概念として導入するのか。
- 既存の $B / M_B / \xi$ / 偏り等から翻訳可能な自然言語概念として扱うのか。
- 特定の文脈・用途にだけ成立する局所的翻訳なのか。

原則として、既存構造から十分に翻訳できる語は Core Primitive へ昇格させず、本辞書に保持する。
