## ■ 0. 位置づけ

本文書は、日常語・哲学語として用いられる**自然言語概念を、RDL の関係記述へ翻訳するための拡張可能な辞書**である。

ここでいう「翻訳」は、一般語義を廃止したり、RDL 独自語へ機械的に置換したりすることを意味しない。自然言語上の概念が、SILN、RIB、有限境界 $B$、`RIB_B`、現在の $M_B$、$F$、関係の偏り、$\xi$ 等を用いた記述では、どのような構造として現れるかを対応づける。

```text
TD_共有語彙.md
= RDL 内部語彙の最小辞書

TD_自然言語概念のRDL的翻訳.md
= 自然言語概念 → RDL 関係記述の翻訳辞書
```

本辞書に置かれる語は、原則として Core Primitive を新設するものではない。既存の RDL 語彙から自然言語概念をどう読めるかを示し、必要に応じて追加・更新する。

## ■ 1. 偏りから翻訳される概念

以下は、自然言語上の「意味・価値」等を、関係ネットワーク上に生じる偏りとして読むための最小翻訳である。

ここでいう**偏りの勾配**は、ある局所状態から後続の解釈・予測・選択・行為等がどの方向へ、どの程度生じやすくなるかを表す説明的表現であり、現段階では Core Primitive として独立させない。

T0 v2.3 では、観測・認識において直接扱う相互作用側の有限断面を `RIB_B` とし、

```text
F = interp(M_B, RIB_B)
```

を標準形とする。したがって「意味」「価値」「意義」等は、対象そのものや `RIB_B` に固定された内容ではなく、**現在の $M_B$ が `RIB_B` を解釈して形成した $F$ と、その後続選択・行為への偏り**として読む。

| 自然言語概念 | RDL 的翻訳 |
| :--- | :--- |
| **意味** | 現在の $B$ で取得された `RIB_B` を $M_B$ が解釈したとき、$F$ として立ち上がり、後続の解釈・予測・選択・行為へ複数方向の偏りを与える**偏りの勾配の束**。対象や `RIB_B` に内在する固定内容とは置かない。 |
| **無意味** | 「関係や偏りが絶対に存在しない」ことではなく、現在の $B / RIB_B / M_B$ のもとで、意味として有効に働く偏りの勾配の束が `F` として立ち上がらない、または判定可能なまとまりを形成しない状態。 |
| **価値** | 現在の $M_B$ が `RIB_B` を解釈した結果として、接近・維持・選好・回避等へ方向と強さを与える偏り。対象に固定された属性ではなく、SILN・RIB・$B$・$M_B$ の関係において立ち上がる。 |
| **意義** | 形成された意味・価値の偏りのうち、現在の自己の選択・行為・更新へ有効に接続する断面。何を表すかだけでなく、**現在の $M_B$ にとって何を変えるか**として読む。 |

したがって、同じ対象となる SILN でも $B$ が変われば取得される `RIB_B` が変わり、$M_B$ が変われば同じ `RIB_B` から形成される $F$ も変わりうる。

```text
同じ SILN
↓ 異なる B
異なる RIB_B
↓ 異なる M_B
異なる F
↓
異なる意味・価値・意義
```

## ■ 2. 確定化しやすい概念の翻訳

RDL 運用において確定化（$\xi=0$ の主張）に陥りやすい日常語・哲学語は、語そのものを禁止・廃棄したり、常に別語へ置換したりする必要はない。

その語が**絶対化・最終化・完全化された構造として読まれうる局面では、`ADDξ(x)` を明示することを推奨する**。

```text
ADDξ(真理)
ADDξ(客観)
ADDξ(安定)
ADDξ(正義)
ADDξ(完成)
```

`ADDξ(x)` は $x$ を否定する記法ではない。語 $x$ と、それが指す局所構造をそのまま保持しつつ、**その有限な切り出しにも未回収関係 $\xi$ が残り、終端閉包されていないことを明示する**。

したがって、日常的・局所的な用法にまで常時 `ADDξ` を要求するものではない。確定化・絶対化・終端化として受け取られる危険がある場合に、閉包を解除するための明示的な運用表記として用いる。

| 自然言語概念 | RDL 的翻訳 |
| :--- | :--- |
| **客観** | **間主観的再現性**。観測者非依存の絶対視点ではなく、異なる観測者・境界間でどの `RIB_B / F` が再現し、どこで差が生じるかを追跡可能であること。誰も有限 $B$ と $\xi$ の条件からは外れない。 |
| **中立・公平** | **偏りの露出と引き直し**。偏りゼロを前提にせず、どの $B / M_B$ で何が取得・除外され、どの方向へ判定が偏っているかを露出し、必要なら $B$ を引き直す。 |
| **真理・絶対** | **$\text{ADD}\xi(\text{真理})$**。禁止せず保持するが、有限な `RIB_B / M_B / F` を終端的な世界全体と同一視しない。 |
| **安定** | **現在の $B$ のもとで、後続 `RIB_B` に対する差異を現在の $M_B$ が許容範囲内で吸収し、機能を維持できている状態**。$\xi=0$ を意味しない。 |
| **破綻・失敗** | **現在の $B / M_B$ では処理できない差異が露出し、再検査・境界更新・再構成を要求する診断情報**。終端ではなく次の有限構造へ移る契機。 |

## ■ 3. 追加原則

自然言語概念を追加するときは、少なくとも次を区別する。

- その語を RDL の新しい基底概念として導入するのか。
- 既存の `SILN / RIB / B / RIB_B / M_B / F / ξ` 等から翻訳可能な自然言語概念として扱うのか。
- 特定の文脈・用途にだけ成立する局所的翻訳なのか。
- 対象側の構造を指しているのか、相互作用側の有限断面を指しているのか、解釈後の $F$ を指しているのか。

原則として、既存構造から十分に翻訳できる語は Core Primitive へ昇格させず、本辞書に保持する。

## ■ 4. 一文圧縮

> **自然言語概念をRDLへ翻訳するときは、対象に固定された意味内容を先に置くのではなく、SILN と RIB の関係から現在の B が取得する `RIB_B`、それを解釈する `M_B`、形成される `F`、そして残る `ξ` へ展開し、その語がどの関係位置で働いているかを明示する。**
