# ρ — 無限解像度仮設
*よく使う概念語彙 / DRAFT v0.1*

---

## 0. 位置づけ

`ρ` は、RDLにおいて**無限解像度仮設**を扱うための暫定的な便利記号である。

現段階では基底概念として確定せず、共有語彙／よく使う概念語彙側で運用し、必要性と耐久性を検査する。

`ρ` を導入する目的は、これまで `Δ → 0` や `Δ = 0` に担わせていた複数の意味を分離することにある。

特に、

- 二つの断面が同一であること
- 断面間隔を小さくすること
- 観測・操作の解像度を上げること
- 無限に細かく区別できると仮設すること

を、同じ `Δ = 0` で表現しないために用いる。

---

## 1. 基本的な意味

`ρ` は、ある境界 `B` の内部で、

> **関係差をどこまで細かく区別して操作するか**

を表す解像度概念として用いる。

必要に応じて、

```text
ρ_B
```

と書き、どの `B` における解像度であるかを明示する。

概略的には、

```text
ρ_B が低い
↓
粗い区別

ρ_B が高い
↓
細かい区別
```

として扱う。

---

## 2. 無限解像度仮設

RDLで実際に行われる観測・記述・操作は有限である。

したがって、実操作として無限の解像度を達成したと主張するものではない。

`ρ → ∞` は、

> **解像度の増加に終端を置かない仮設**

を表す。

つまり、

```text
ρ_1 < ρ_2 < ρ_3 < ...
```

と解像度を上げ続けることが可能であると仮設し、その操作系列に最終的な最小区別単位を置かない。

この意味で、

```text
ρ → ∞
```

は**無限解像度仮設**であり、実際に無限個の観測や操作を完了したことを意味しない。

---

## 3. `Δ` との区別

`Δ` と `ρ` は役割を分ける。

### `Δ`

`Δ` は、切り出された二つの断面・状態・観測点の**操作的な隔たり**を表す。

```text
S_0
│
│ Δ
│
S_1
```

### `ρ`

`ρ` は、その変化・関係を**どの細かさまで区別して切り出すか**を表す。

```text
低い ρ

A ───────── B
```

```text
高い ρ

A ─ a1 ─ a2 ─ a3 ─ B
```

したがって、

```text
Δ = 隔たり
ρ = 解像度
```

であり、同一ではない。

解像度を上げると結果として扱う `Δ` が小さくなる場合はあるが、

```text
ρ = 1 / Δ
```

をRDLの一般定義として固定しない。

両者の対応関係は、使用するモデルや尺度によって設定される。

---

## 4. `Δ = 0` と分離する理由

`Δ = 0` は、通常、

```text
二つの断面に隔たりがない
```

という意味に読める。

その場合、

```text
S(t + Δ) = S(t)
```

となり、二断面の差によって変化を追う操作が成立しにくくなる。

一方、

```text
ρ → ∞
```

は、二つの断面を同一化することではない。

むしろ、

> **二断面のあいだに、さらに細かな差を切り出せる可能性に終端を置かない**

という仮設である。

したがって、

```text
Δ = 0
```

と

```text
ρ → ∞
```

は明確に区別する。

---

## 5. `ξ` との関係

`ρ` を導入するうえで最も重要なのは、

```text
ρ → ∞  ≠  ξ → 0
```

という区別である。

解像度をどれだけ高くする仮設を置いても、それによって関係が完全に回収されたことにはならない。

RDLでは有限な `B` による操作には `ξ` が残る。

したがって、

```text
有限 B
+
ρ を高くする
↓
より細かな関係差を操作可能にする
+
なお ξ が残る
```

と扱う。

無限解像度仮設は、完全記述仮設ではない。

---

## 6. 連続との関係

「連続」を扱う際、これまで

```text
Δ → 0
```

という表現を用いると、

- 隔たりが消える
- 同一断面になる
- 無限に細かく観測する

という意味が混ざりやすかった。

`ρ` を使う場合、RDLでは連続を暫定的に、

> **解像度の増加に終端を置かない記述仮設**

として扱うことができる。

概略的には、

```text
ρ → ∞
```

を許す記述形式として「連続」を読む。

ただし、

```text
連続 = ρ → ∞
```

を存在論的な最終定義として確定するものではない。

これはあくまで、RDLにおいて連続概念を操作するときの便利な読み方である。

また、連続仮設を採用しても `ξ` は消えない。

---

## 7. 尺度との区別

`ρ` は「尺度」とも区別する必要がある。

概略的には、

> **尺度**
> = どの範囲・大きさの関係を主に扱うか

> **解像度 `ρ`**
> = その範囲内部をどこまで細かく区別して扱うか

とする。

たとえば同じ都市を `B` として扱っていても、

```text
低い ρ
→ 区・地域単位

高い ρ
→ 街区・建物・個体単位
```

のように、Bの大まかな範囲を維持したまま内部の区別を細かくできる。

ただし実際には、尺度変更と解像度変更が同時に起きる場合も多い。

必要に応じて両者を分けて記述する。

---

## 8. 時間との関係

時間を扱う場合、変化を有限な断面として切り出すと、

```text
S_0 → S_1 → S_2
```

のような離散表現になる。

`ρ` を上げると、

```text
S_0
→ s_01
→ s_02
→ s_03
→ S_1
```

のように、より細かな変化を区別して扱える。

`ρ → ∞` を仮設すると、変化の切断に最終的な最小単位を置かない記述が可能になる。

ただし、これは「時間そのものが連続している」という存在論的主張ではない。

また、時間感覚や履歴拘束そのものを `ρ` が生み出すわけでもない。

`ρ` は、それらをどの解像度で切り出し操作するかを補助する記号である。

---

## 9. 空間との関係

空間を広い `B` として扱う場合にも `ρ` は利用できる。

同じ空間 `B_space` の内部でも、

```text
低い ρ
→ 大きな境界だけを見る

高い ρ
→ より細かな局所境界や境界間関係を見る
```

という違いが生じる。

したがって、

```text
B = どこまでをひとまとまりとして扱うか
ρ = その内部をどこまで細かく区別するか
```

という役割分担ができる。

---

## 10. 操作上の注意

`ρ` は実測値として必ず数値化できるとは限らない。

用途によっては、

```text
ρ_low
ρ_mid
ρ_high
```

のような相対的な解像度として扱ってもよい。

また、対象によって解像度の意味は異なる。

- 空間的解像度
- 時間的解像度
- 概念的解像度
- 観測的解像度
- 記述的解像度
- 操作的解像度

などがありうる。

必要であれば、

```text
ρ_B^space
ρ_B^time
ρ_B^concept
```

のように補助ラベルを付けてもよい。

ただし、現段階では記号体系を過剰に増やさず、まず `ρ` / `ρ_B` を基本形として用いる。

---

## 11. 基底との関係

`ρ` は、現時点では基底概念として確定しない。

ただし、

- 時間
- 空間
- 連続／離散
- 観測
- 操作
- 尺度
- `Δ`
- `ξ`

など複数の領域で繰り返し必要になる可能性がある。

実際のRDL運用において、

> `ρ` を除くと各所の説明や操作が不自然になる

ことが繰り返し確認された場合、T0 SPEC等への昇格を検討する。

それまでは、

> **仮設すると操作が明瞭になる便利語彙**

として扱う。

---

## 12. 現時点での暫定仕様

```text
ρ
= 解像度を表す便利記号

ρ_B
= 境界 B 内での操作解像度

ρ → ∞
= 解像度増加に終端を置かない無限解像度仮設

ρ → ∞ ≠ Δ = 0

ρ → ∞ ≠ ξ → 0
```

`Δ` は断面間の隔たり、`ρ` はその関係をどこまで細かく切り分けて操作するかを表す。

---

## 13. 一文圧縮

> **RDLにおける `ρ` は、ある境界 `B` の内部で関係差をどこまで細かく区別して操作するかを表す解像度概念であり、`ρ → ∞` はその解像度増加に終端を置かない無限解像度仮設を表す。これは `Δ = 0` のような断面同一化でも、`ξ → 0` のような完全回収でもなく、有限な操作では離散的に切り出される関係を、必要に応じて終端なしに微細化可能として扱うための便利記号である。**
