# 展開・選別・再構成の関係

*RDL-Core / Explanation / T1 / v0.2*  
*依存：T0 BASE / SPEC v2.3、T1_SILN操作層*  
*最終同期：2026-09-14*

---

## ■ 0. 概要

本文書は、T1 SILN操作層における中核サイクル **「SILN展開 → 検査と選別 → 再構成」** の三相の機能的な違い、不可欠性、相互連動を解説する。

```text
対象化された SILN / 現在の M_B
        ↓ B・観測・Probe
RIB_B列 / F / E / H / 既知構造
        ↓
SILN展開（広げる）
        ↓
検査と選別（絞る）
        ↓
再構成（M_B' として定着）
        ↓
後続 RIB_B' の解釈へ戻る
        ↺ 必要なら ΔB / 再展開
```

---

## ■ 1. 三相の役割と不可欠性

### 1.1 SILN展開だけがある場合

- **役割**：対象化した SILN、`RIB_B`、履歴、既知理論から、関係・状態・候補構造の可能性空間を広げる。
- **単独時の問題**：候補を広げ続けても、残す基準がなければ発散する。

```text
展開だけ
→ 候補生成の増大
→ 何を残すか決まらない
```

### 1.2 検査と選別だけがある場合

- **役割**：候補へ負荷・比較・評価を与え、現在の $B$・用途・制約に対して残存可能な関係を絞る。
- **単独時の問題**：既存候補を落とすだけで、新しい可能性を開けない。

```text
選別だけ
→ 既存枠内の最適化
→ 未知への候補生成が弱くなる
```

### 1.3 再構成だけがある場合

- **役割**：選別された残存関係を、新しい自己側有限関係拘束構造 $M_B'$ として定着させる。
- **単独時の問題**：展開・検査を経ずに外部構造を取り込むと、有効範囲や破断条件が分からないまま固定される。

```text
再構成だけ
→ 無検査の取り込み
→ 過剰適合・教義化・条件無視
```

---

## ■ 2. 三相の動的な協調

### Phase 1：SILN展開

```text
対象化された SILN
+ RIB_B列
+ F / E / H
+ 履歴・既知理論
      ↓
複数の M_{B,target} / {M_B^i} / 破断候補を開く
```

ここでは「何があり得るか」を広げる。Probe を用いる場合は相互作用条件を変え、その結果として得られる `RIB_B^{probe,k}` を探索材料にする。

### Phase 2：検査と選別

```text
候補群
+ RIB_B / Probe結果
      ↓
統計・実験・シミュレーション・T2耐久検査等
      ↓
Selection_{B,goal}
      ↓
retain / reject / defer
```

選別は「真理か否か」の最終判定ではない。現在の $B$・用途・許容損失に対して、どの関係がどこまで残るかを絞る。

### Phase 3：再構成

```text
残存関係
+ 有効な B / RIB 条件
      ↓
M_B'
      ↓
RIB_B' を解釈する通常運転へ復帰
```

再構成では、単に候補を保存するのではなく、後続する作用断面を解釈・予測・応答できる自己側構造へ組み込む。

---

## ■ 3. Probe は三相の外ではない

Probe は独立した「未知抽出器」ではない。

```text
Probe_B(target, condition_k)
  → RIB_B^{probe,k}

F_k = interp(M_B, RIB_B^{probe,k})
```

この結果は展開材料となり、検査・選別の証拠となり、最終的に再構成の有効条件へ引き継がれる。

つまり Probe は、**相互作用条件を有限に揺らし、三相サイクルへ新しい差分を供給する接触操作**である。

---

## ■ 4. 破断と ΔB による再ループ

再構成された $M_B'$ も有限であり、$\xi'$ を伴う。

```text
M_B'
 ↓
後続 RIB_B'
 ↓
F_new → E_new → H_new
```

現在の境界では不整合を吸収できなくなれば、$B$・Probe・Selection・候補構造のいずれかを再対象化し、必要に応じて $\Delta B$ を行って Phase 1 へ戻る。

この再ループは「永久に同じ処理を回す」という意味ではなく、**有限構造を終端化せず、必要なときに形成経路へ戻れること**を意味する。

---

## ■ 5. 一文圧縮

> **T1 の展開・検査と選別・再構成は、`RIB_B` と既存構造から可能性を広げ、条件に耐える関係を絞り、その残存関係を新しい $M_B'$ として定着させて後続相互作用へ戻す三相である。三相のいずれか一つだけでは、発散・硬直・無検査固定化のいずれかに偏りやすい。**
