# 04_記述道具とSELF

*RDL-Core / Explanation / v1.0*  
*依存：T0 BASE / SPEC v2.3*  
*最終同期：2026-09-15*

## 0. 目的
本文書は、RDL の語彙・概念を「世界の終端真理を表す名辞」ではなく、有限な関係を扱うための記述道具として位置づけ、その道具自身にも `[SELF]` を適用する原則をまとめる。

## 1. RDL語彙は道具である
SILN、RIB、B、M_B、RIB_B、F、E、H、θ、ξ などは、宇宙に一対一対応する実体名として置くのではない。

目的は、

```text
何を構造として見ているか
何を作用として見ているか
どこで有限化したか
どこから解釈が始まったか
どこに不整合が残ったか
```

を追跡しやすくすることである。

> **RDL語彙は、関係運動を有限に切り分け、比較・操作・更新可能にする道具箱である。**

## 2. 道具であることは恣意を意味しない

```text
自由に仮設できる
≠
自由に成立させられる
```

語彙・B・モデルは後続 `RIB_B`、予測、実験、実運用、他者との比較によって拘束される。

RDL は「世界を好きに作れる」とは置かない。一方で、有限な記号体系が世界を完全に写し取るとも置かない。

## 3. 強い概念も特権化しない
RDL は「存在」「空間」「時間」「実在」「連続」「離散」「数」「真理」「神」などを特別に禁止しない。

ただし、これらを記述開始時点の特権的基底実体として固定せず、必要なら SILN として対象化し、現在の B のもとで道具として使う。

```text
特殊に否定しない
特殊に特権化しない
基底実体として固定しない
必要なら対象化して使う
```

## 4. `[SELF]`：自己例外化禁止

```text
∀x ∈ dom(RDL): x は RDL 操作の対象になりうる
RDL ∈ dom(RDL)
```

RDL が有限構造・境界・未回収関係を扱うなら、その条件から RDL 自身だけを除外しない。

RDL の公理、語彙、仕様、文書体系も有限な関係構造として対象化できる。

```text
現在の RDL
↓
M_B(RDL)
↓ 対象化
関連する批判・反例・運用差分を RIB_B として取得
↓
展開 → 検査・選別 → 再構成
↓
M_B'(RDL) + ξ
```

## 5. 自己適用 ≠ 自己完全性

```text
Self-applicability ≠ Self-completeness
```

RDL が自分を対象化できることから、自身の全破断や全未回収関係を検出できることは導かれない。

自己適用は「自分を完全に理解できる」という主張ではなく、**自分も更新対象に含める規律**である。

## 6. 有限でも比較できる
有限であることは相対主義を意味しない。

構造は、たとえば、

```text
耐久性
再現性
予測性
破断範囲
操作上の有効性
更新可能性
```

などで比較できる。

```text
有限である ≠ 何でも同じ
```

である。

## 7. 語彙改訂も通常運転
旧概念や語彙が混同を生み、より少ない仮定で高い操作性を持つ区分が得られれば、語彙自体を再構成してよい。

RDL における語彙変更は失敗の隠蔽ではなく、`[SELF]` の通常運転である。

## 8. 一文圧縮
> **RDLの語彙は、関係を有限に切り分けて追跡・比較・操作するための道具であり、終端真理を表す特権語ではない。そのためRDL自身の公理・語彙・文書も `[SELF]` により同じ検査・再構成の対象となる。自己適用は自己完全性ではなく、自己例外化を避けるための規律である。**
