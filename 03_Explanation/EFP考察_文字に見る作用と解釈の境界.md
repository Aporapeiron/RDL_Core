## 位置づけ

この文書は、旧 `EFP / 素流圧` 体系で「文字」「作用」「解釈」の境界を考察した履歴文書である。

T0 BASE / SPEC v2.3 では `EFP` を廃止し、

```text
RIB   = Relational Interaction Bundle
RIB_B = B 依存の有限作用断面
F     = interp(M_B, RIB_B)
```

へ再編した。

内容の主旨――

- 文字形状そのものと意味を同一視しない
- 同様の作用でも $M_B$ が異なれば異なる F が成立しうる
- 「意味不明」「記号」「傷」「線」もすでに F である
- 文字を意味の容器ではなく関係の再接続端子として考える

――は新体系でも有効であるため、改訂版を次の文書へ移した。

> [**RIB_B考察_文字に見る作用断面と解釈の境界.md**](./RIB_B考察_文字に見る作用断面と解釈の境界.md)

旧 `EFP` の定義・式・名称は歴史的参照のためこのファイル名にのみ残し、現在の概念定義には使用しない。
