# 05_B から M_B・RIB_B と ξ が生じる理由

*RDL-Core / Explanation / Aporapeiron と SILN / 05 / v0.2*  
*依存：T0 基底措定（BASE）v2.3 / 04_記述と離散化.md*  
*最終同期：2026-09-14*

---

## ■ 0. 目的

本文書は、Explanation 全体の**蝶番（関節）**として、有限境界 $B$ を引くと、なぜ構造側の有限断面 $M_B$、相互作用側の有限作用断面 `RIB_B`、そして未回収関係 $\xi$ が同時に成立するのかを解説する。

旧体系では、$B$ により「自己側なら $M_B$、対象側なら SILN」が生じると説明していた。現在の T0 ではこの整理を改め、**SILN は先に置かれる基底構造**とする。$B$ が成立させるのは、SILN と RIB 群を現在の用途・問いに対して有限に扱うための断面である。

---

## ■ 1. B による有限化の三側面（中心分岐）

何かを記述・観測・操作するには、差異、尺度、時間幅、観測位置、用途・問いなどを選ぶ必要がある。

この有限化を RDL では $B$ と表す。

```text
SILN と複数の RIB
        ↓
用途・問いに応じた有限境界 B
        ↓
┌────────────────┬────────────────┐
│ 構造側          │ 相互作用側      │
│ M_B             │ RIB_B           │
└────────────────┴────────────────┘
          ＋ ξ
```

ここで、

- $M_B$ は、ある SILN を自己側・解釈側として現在の $B$ のもとで有限に保持した関係拘束構造。
- `RIB_B` は、一つ以上の RIB を現在の $B$・観測位置・時間断面・対象方向などから切り出した未解釈の有限作用断面。
- $\xi$ は、その有限化では回収されない関係。

である。

---

## ■ 2. SILN と M_B は同義ではない

SILN は基底構造であり、$M_B$ はその SILN を特定の役割・境界のもとで有限に扱う自己側断面である。

```text
SILN
= RDL が扱う有限構造の基本形

M_B
= SILN を現在の B のもとで自己側・解釈側として保持した有限関係拘束構造
```

したがって、

```text
B → SILN
```

ではない。

より正確には、

```text
SILN
 ↓ B
M_B + ξ
```

と読む。

外部対象を T1 で扱うときも、それを「B が新しく作った SILN」とするのではなく、**SILN として対象化し、現在の B のもとで $M_{B,target}$ 等の有限モデルを推定する**。

---

## ■ 3. RIB と RIB_B の関係

SILN は複数の RIB との相互作用の中で構造を保持する。

しかし、RDL がある問いについて全 RIB を完全取得するとは仮定しない。

```text
{RIB_1, RIB_2, ..., RIB_n, ...}
        ↓ B
      RIB_B + ξ
```

たとえば人間を扱う場合でも、重力、大気圧、床反力、温度、光、音、言語、制度、他者からの応答など多数の RIB が関与している。

「姿勢保持」を問う $B$ では重力・床反力・筋張力などが強く `RIB_B` に入り、「対話成立」を問う $B$ では音声・意味・応答タイミング・社会的期待などが強く切り出されうる。

`RIB_B` は RIB 全体ではなく、**現在の問いに対する有限作用断面**である。

---

## ■ 4. ξ はどこに生じるのか

$\xi$ は「B の外側にある物質」や「未知の貯蔵庫」ではない。

現在の有限化で回収されなかった関係の総称である。

```text
ξ が現れうる断面：
・選択の外
・射影の外
・解像度の下
・時間幅の外
・観測位置から見えない関係
・B 自身を正当化する前提
・読解・解釈に必要な外部文脈
・文書化・媒体による捨象
・相互作用の後続変化
```

したがって $M_B$ と `RIB_B` の双方が $\xi$ を暗黙に伴う。

---

## ■ 5. なぜ有限断面と ξ が同時に立つのか

有限境界 $B$ を引くということは、構造的に、

```text
1. 何かを選び、それ以外を選ばない
2. 特定の差異を残し、他の差異を同一視・捨象する
3. 特定の尺度・時間幅・観測位置を採る
4. 特定の関係軸へ射影し、他の関係軸を切り落とす
```

ことを含む。

そのため、有限に扱える断面を得ることと、同じ有限化では回収されない関係が残ることは分離できない。

```text
有限境界 B
      ├─ 構造側で保持された断面      → M_B
      ├─ 相互作用側で保持された断面  → RIB_B
      └─ 回収されない関係            → ξ
```

ただし、これは `M_B + RIB_B + ξ` が世界全体を厳密に分割した完全な三分割である、という意味ではない。$\xi$ 自体も有限記述であり、RDL は全体を完全列挙したとはみなさない。

---

## ■ 6. Aporapeiron との関係

$\xi$ と Aporapeiron は同義ではない。

```text
ξ
= 現在の B で回収されない関係

Aporapeiron
= M_B / RIB_B が ξ を伴い、
  後続相互作用によって再検査・破断・更新・再構成へ
  開かれ続ける非終端的な関係運動
```

Aporapeiron は「こぼれた側」という静的な場所ではない。

---

## ■ 7. 次の問い：ξ = 0 の有限境界 B は成立するか

ここまでで、現在の RDL は、有限境界 $B$ から $M_B / RIB_B$ を成立させるとき $\xi$ が残る構造を採用している。

では、理論・観測・技術を十分に洗練すれば、

```text
∃B_finite : ξ(B) = 0
```

となる完全閉包は成立するのか。

この問いを次文書 [**06_ξ残存性.md**](./06_ξ残存性.md) で検査する。

---

## ■ 8. 一文圧縮

> **有限境界 $B$ は SILN を作るのではなく、SILN と複数の RIB を現在の用途・問いに対して有限化し、構造側に $M_B$、相互作用側に `RIB_B` を成立させる。同じ有限化では回収されない関係が $\xi$ として残り、この有限断面と未回収性の共存が RDL の非終端的な更新可能性を支える。**
