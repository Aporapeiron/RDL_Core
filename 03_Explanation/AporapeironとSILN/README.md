# Aporapeiron と SILN 解説群

*RDL-Core / Explanation / Aporapeiron と SILN / README / v0.1*
*最終同期：2026-08-24*

---

## ■ 0. 一文定義

> **SILN は有限境界 $B$ のもとで操作対象として切り出された構造（食材）であり、現在の自己が保持する整合構造（身体）を $M_B$ と呼ぶ。Aporapeiron は有限 $B$ が常に未回収関係 $\xi$ を伴い終端化しない非閉包条件であり、RDL は「閉じ切らないが、扱える」ことをその基底とする。**

---

## ■ 1. 中心構造

```text
有限境界 B による切り出し
      ├─ 操作対象として扱う ──→ SILN（切り出して扱える側：食材）
      └─ こぼれた残り       ──→ ξ   （Aporapeiron：閉じ切らない側）

現在の自己側で保持されている整合構造 ──→ M_B（身体）
```

```text
【T1 代謝への接続】
現在の自己 M_B
      │
      │ SILN（食材）を取り込む
      ▼
   SILN
    ↓
   展開（素材へ開く）
    ↓
   検査と選別（適合構造を絞る）
    ↓
   再構成（血肉化）
    ↓
   M_B'（更新された身体）
```

### 1.1 SILN
有限境界 $B$ のもとで、RDL 操作の対象としてひとまとまりに切り出された関係構造（操作対象としての身分・食材）。

### 1.2 M_B
現在の境界 $B$ の内部で、観測・処理の主体側が保持している整合構造（自己の身体・操作表現）。

### 1.3 Aporapeiron
有限境界 $B$ による閉包が未回収関係 $\xi$ を伴い、現在の記述を終端的閉包として固定できないという非閉包条件（使えても閉じ切ったとはみなさない側）。

```text
SILN        : 切り出して扱える側（操作対象の成立）
M_B         : いま何でできているか（自己側の保持構造）
Aporapeiron : 切り出しても閉じ切らない側（非閉包・更新余地）
```

> **「SILN は何を食べるかの区分、M_B はいま何でできているかの区分、Aporapeiron は食べても世界は閉じ切らないという条件。」**

## ■ 3. 全体の読み筋

```text
関係として記述する
      ↓
偏りから境界候補が生じる
      ↓
有限境界 B を選ぶ
      ↓
記述・単位化する
      ↓
保持される関係構造（自己側に保持すれば M_B、対象側として扱えば SILN） ＋ ξ が生じる
      ↓
操作対象として扱える（SILN）
同時に
ξ が残るため終端化しない（Aporapeiron）
      ↓
安定と非閉包が共存する（閉じ切らないが、使える）
      ↓
必要に応じて ΔB と再構成が可能（自己消化と更新）
      ↓
その SILN を空間・時間・数・理論などの記述道具として利用できる
      ↓
RDL 自身も同じ代謝構造の外には置かれない（[SELF]）
```
