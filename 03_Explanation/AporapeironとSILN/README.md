## ■ 0. 一文定義

> **SILN は RDL が扱う基底構造であり、非線形関係ネットワーク上で複数の RIB と相互作用しながら動的に構造を保つ。RDL は用途・問いに応じた有限境界 $B$ によって、構造側を $M_B$、相互作用側を `RIB_B` として有限化する。そこには常に未回収関係 $\xi$ が残り、有限構造を終端化せず再検査・再構成へ開いたままにする非終端的な関係運動を Aporapeiron と呼ぶ。**

---

## ■ 1. 中心構造

```text
非線形関係ネットワーク
        ↓
SILN ↔ {RIB_1, RIB_2, ..., RIB_n, ...}
        ↓ 用途・問いに応じた有限境界 B
┌────────────────┬────────────────┐
│ 構造側          │ 相互作用側      │
│ M_B             │ RIB_B           │
└────────────────┴────────────────┘
          ＋ ξ
          ↓
F → E → H → 維持 / M_Δ → 再構成
```

### 1.1 SILN
**Survival-biased Integration of Local Linear Approximations in a Nonlinear Network**。RDL が扱う有限構造の基本形。自己側・対象側のどちらかに限定されない。

### 1.2 RIB
**Relational Interaction Bundle**。非線形関係ネットワーク上で成立する相互作用束。重力・圧力・接触・光・音・情報・他 SILN の応答など、複数の RIB が同時に SILN へ関与しうる。

### 1.3 M_B
ある SILN を、現在の有限境界 $B$ のもとで自己側・解釈側として保持した有限関係拘束構造。

### 1.4 RIB_B
一つ以上の RIB から、用途・問い・観測位置・時間断面・対象方向などに応じて $B$ が切り出した未解釈の有限作用断面。

### 1.5 ξ
現在の有限境界 $B$ では回収されない関係。$M_B$ と `RIB_B` の双方に伴う。

### 1.6 Aporapeiron
$M_B / RIB_B$ が $\xi$ を伴い、後続相互作用によって再検査・破断・更新・再構成へ開かれ続ける非終端的な関係運動。$\xi$ の別名でも、SILN の反対物でもない。

## ■ 2. T1 代謝への接続

```text
対象化された SILN / 現在の M_B
        ↓ B・観測・Probe
RIB_B列 / F / E / H / 既知構造
        ↓
SILN展開
        ↓
検査と選別
        ↓
残存関係
        ↓
再構成
        ↓
M_B'
        ↓
後続 RIB_B' の解釈へ復帰
```

旧「SILN＝食材」という説明は Core の定義から外す。対象化された SILN や候補構造を食材に喩えることは可能だが、あくまで T1 の説明比喩である。

## ■ 4. 全体の読み筋

```text
SILN と RIB を関係ネットワーク上で捉える
      ↓
偏り・差異を見る
      ↓
用途・問いに応じて B を置く
      ↓
M_B / RIB_B + ξ
      ↓
有限に記述・解釈・操作する
      ↓
安定して機能する
      ↓
後続 RIB_B との不整合・破断が生じうる
      ↓
必要なら ΔB / 展開 / 検査 / 選別 / 再構成
      ↓
M_B'
      ↓
そこにも ξ が残る
      ↓
RDL 自身も同じ運動の外には置かれない（[SELF]）
```

> **閉じ切らない。しかし、扱える。**
