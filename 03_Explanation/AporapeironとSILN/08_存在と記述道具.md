## ■ 0. 目的

本文書は、RDL が「存在」「空間」「時間」「実在」「連続」「離散」「数」「真理」「神」といった強い概念を、否定も特権化もせず、**SILN として対象化可能な有限構造・記述道具**としてどのように扱うかを解説する。

---

## ■ 1. 「道具」と SILN の関係

SILN は RDL の基底構造であり、「操作対象として皿に載ったもの」だけを意味しない。

理論、数学モデル、時間概念、空間表現、分類体系、制度なども、それぞれ有限な関係構造として成立しているなら SILN として対象化できる。

そのうち、特定の用途・問いに対して利用している機能状態を **記述道具** と呼ぶ。

```text
SILN
= RDL が扱う有限構造の基本形

対象化
= ある SILN を現在の問いの検査・操作対象として扱うこと

道具
= その SILN / 有限モデルを、計算・予測・比較・伝達などの目的に利用している状態
```

---

## ■ 2. 基本姿勢：基底実体として先に固定しない

RDL は、強い概念を個別に否定しない。

```text
「空間は幻覚である」
「真理は存在しない」
「神は存在しない」
```

といった結論を基底に置くのではなく、

> **それらを記述開始時点の特権的な基底実体として固定せず、まず SILN・関係・相互作用として扱う。**

という方法論を採る。

基本姿勢は次の四点に圧縮できる。

```text
1. 特殊に否定しない
2. 特殊に特権化しない
3. 基底実体として固定しない
4. 必要なら SILN として対象化し、道具として使う
```

---

## ■ 3. 記述道具としての各種表現形式

| 概念・形式 | RDLでの利用の仕方 |
| :--- | :--- |
| **空間（Space）** | 近接・移動・配置・距離などを扱う表現形式。 |
| **時間（Time）** | 順序・変化・履歴・遅延などを追跡する表現形式。 |
| **存在・物体（Entity）** | 安定した関係パターンを操作単位として扱うラベル。 |
| **連続（Continuum）** | 滑らかな変化や勾配を記述する道具。 |
| **離散（Discrete）** | 記号・グラフ・状態遷移・イベントを扱う道具。 |
| **数・数学（Math）** | 定義・境界・操作規則・比較を明示し、再現性を高める記号体系。 |
| **真理（Truth）** | 特定の $B$・用途・検査条件で高い拘束力・耐久性を持つ記述へ与えるラベルとして扱いうる。 |
| **神（God）** | 宗教・哲学・文化・個人経験における高次概念として、他の概念と同様に有限に記述・比較・検査しうる。 |

これらを使うときも、実際に操作するのは現在の有限境界に応じた $M_B$、`RIB_B`、モデル、解釈であり、概念の全体を完全取得したとみなさない。

---

## ■ 4. 終端化を標準状態としない

RDL は特定の概念を扱うことを禁止しない。

ただし、有限境界 $B$ で得られた構造・モデルを、例外のない終端的閉包として固定することを標準運用にしない。

```text
有限な SILN / モデルとして使う
+ 適用 B・RIB 条件を保持する
+ ξ を残す
→ 更新可能な道具

ξ = 0 の終端構造として固定する
→ 想定外の RIB_B・差異・破断を取り込みにくくなる
```

---

## ■ 5. RDL での基本的な記述順序

```text
非線形関係ネットワーク上の SILN / RIB を見る
      ↓
用途・問いに応じて B を引く
      ↓
構造側      → M_B / M_{B,target}
相互作用側  → RIB_B
      ↓
必要に応じて空間・時間・数・連続・離散などの道具を使う
      ↓
解釈・比較・検査・再構成する
```

この順序により、異なる科学理論・哲学概念・制度・記述形式を、それぞれの有効範囲と未回収関係を保持しながら利用しやすくなる。

---

## ■ 6. 一文圧縮

> **RDL でいう記述道具とは、SILN として対象化可能な有限構造や表現形式を、特定の用途・問いに対して利用している機能状態である。存在・空間・時間・数などを基底実体として先に固定せず、必要に応じた $B$ のもとで有限に使い、$\xi$ を残したまま再検査可能に保持する。**
