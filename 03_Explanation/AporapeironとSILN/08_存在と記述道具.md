## ■ 0. 目的

本文書は、RDL が「存在」「空間」「時間」「実在」「連続」「離散」「数」「真理」「神」といった伝統的な強い概念を、**否定も特権化もせず、操作対象構造（SILN）の利用形態（記述道具）としてどのように位置づけるのか**を解説する。

---

## ■ 1. 「道具」と SILN の関係

RDL において「記述道具」とは、有限境界 $B$ のもとで成立した操作対象構造（SILN）を、特定の目的に対して利用している機能状態を指す。

```text
SILN（操作対象としての身分）
= 有限境界 B のもとで、ひとまとまりの操作対象として切り出された安定関係構造

道具（機能状態）
= その SILN が、特定の目的（計算・予測・比較・伝達など）のために利用されている状態
```

理論、数学モデル、時間概念、空間表現、分類体系、制度などは、特定の境界 $B$ のもとで SILN（対象構造）として切り出しうる。そのうち特定の目的のために利用されるものを「道具」と呼ぶ。

---

## ■ 2. 基本姿勢：基底実体として先に固定しない

RDL は、個別科学や哲学・宗教が掲げてきた強い概念に対して、個別的な否定論を積み上げない（「空間は幻覚だ」「真理など存在しない」とは言わない）。

RDL の立場は、**「存在・空間・時間などを記述開始時点の基底実体として先に固定しない。まず関係として記述する」** という方法論的な構えである。

```text
【概念に対する基本姿勢】
1. 特殊に否定しない        : 概念そのものを無効や幻覚として切り捨てない。
2. 特殊に特権化しない      : それらを「世界そのものの絶対の土台・唯一の真理」として崇拝しない。
3. 基底実体として固定しない: 記述の開始時点で最初から固定された前提に置かない。
4. 必要なら道具として使う  : 有限境界 B のもとで切り出された対象構造（SILN）として利用する。
```

---

## ■ 3. 記述道具としての各種表現形式

各種の概念は、有限境界 $B$ のもとで操作対象構造（SILN）として切り出され、目的に応じて道具として利用可能となる。

| 概念・形式 | SILN として切り出された構造の利用場面（道具としての働き） |
| :--- | :--- |
| **空間（Space）** | 近接・移動・配置・距離などを扱うための表現形式。 |
| **時間（Time）** | 因果・順序・変化・履歴などを追跡するための表現形式。 |
| **存在・物体（Entity）** | 一時的に安定した関係パターンを操作単位として切り出すためのラベル（対象構造 SILN）。 |
| **連続（Continuum）** | 滑らかな変化や全体的な勾配をモデル化するための記述道具。 |
| **離散（Discrete）** | 記号・グラフ・状態遷移・論理演算などを扱うための記述道具。 |
| **数・数学（Math）** | 境界・定義・操作規則を明示的かつ厳密に管理し、記述の再現性を高めるための記号体系。 |
| **真理（Truth）** | 特定の境界 $B$ のもとで高い耐久性・整合性を持つ記述を指すラベルとして利用可能。 |
| **神（God）** | 宗教・哲学・文化・個人経験などで用いられる高次概念として、他の概念と同様に $B$ 依存で記述・検査可能。 |

---

## ■ 4. 終端化を標準状態としない

RDL は、特定の概念を扱うこと自体を禁止しない。
ただし、**「有限境界 $B$ で得られた構造を、例外のない終端的閉包（$\xi=0$）として確定すること」を標準運用としない**。

```text
・暗黙の ξ を自覚しながら SILN（道具）として用いる ──→ 健全な仮設運用
・「これは絶対確定であり ξ=0 だ」と終端化する       ──→ 予期せぬ差異に対応しにくくなる
```

絶対化を禁止するからではなく、**終端化しない（Aporapeiron を保持する）方が $[B\text{-}\xi]$ と整合的であり、運用上はるかに頑健だから**である。

---

## ■ 5. RDL での基本的な記述順序

```text
関係を記述基底に置く
      ↓
有限境界 B で対象・単位を切り出す（SILN の成立）
      ↓
自己の身体（M_B）に取り込み操作する
      ↓
必要に応じて、空間・時間・数・連続・離散などの表現形式（道具）を使う
```

この記述順序を採ることで、RDL は異なる学問体系や理論モデルを、それぞれの有効範囲と未回収関係を保持したまま、必要に応じて借用・利用しやすくなる。
