# 05_T1 展開・検査・再構成

*RDL-Core / Explanation / v1.0*  
*依存：T0 BASE / SPEC v2.3 / T1 SILN操作層*  
*最終同期：2026-09-15*

## 0. 目的
本文書は、T1 SILN操作層の中核サイクル **展開 → 検査・選別 → 再構成** を一枚にまとめる。

T1 は、静的な分類体系ではなく、SILN が複数の RIB と相互作用しながら保持・破断・再構成されることを前提に、必要なとき形成経路へ戻る操作系である。

## 1. 全体像
```text
対象化された SILN / 現在の M_B
        ↓ B・観測・Probe
RIB_B列 / F / E / H / 既知構造
        ↓
展開（広げる）
        ↓
検査・選別（絞る）
        ↓
再構成（M_B' として定着）
        ↓
後続 RIB_B' の解釈へ戻る
        ↺ 必要なら ΔB / 再展開
```

## 2. 展開
展開は、対象化した SILN、`RIB_B`、履歴、既知理論から、関係・状態・候補構造の可能性空間を広げる操作である。

```text
展開だけ
→ 候補生成が増える
→ 何を残すか決まらない
```

したがって単独では完結しない。

## 3. 検査・選別
候補へ負荷・比較・評価を与え、現在の B・用途・制約に対して残存可能な関係を絞る。

```text
候補群
+ RIB_B / Probe結果
↓
統計・実験・シミュレーション・耐久検査等
↓
Selection_{B,goal}
↓
retain / reject / defer
```

選別は真理の最終判定ではなく、**どの条件で何が残るか**を記録する操作である。

## 4. 再構成
残存関係を、後続する作用断面を解釈・予測・応答できる新しい自己側構造 $M_B'$ として定着させる。

```text
残存関係
+ 有効な B / RIB 条件
↓
M_B'
↓
通常運転へ復帰
```

展開・検査なしに外部構造をそのまま取り込むことは、条件無視や過剰固定化を起こしやすい。

## 5. Probe
Probe は未知を直接取り出す装置ではない。

```text
Probe_B(target, condition_k)
→ RIB_B^{probe,k}

F_k = interp(M_B, RIB_B^{probe,k})
```

相互作用条件を有限に揺らし、その結果として得られる差分を展開・検査・再構成へ供給する接触操作である。

## 6. 外部理論の借用
RDL は既存理論や解析器を一から再発明しない。

```text
外部理論・手法
↓ SILN として対象化
現在の問いに関係する構造を展開
↓
検査・選別
↓
利用可能な関係を M_B' へ再構成
```

重要なのは、外部理論を絶対化することでも、無理にRDL語彙へ変換することでもなく、**どの B・RIB 条件で機能するかを保持しながら使うこと**である。

## 7. 「代謝」という比喩
T1 はしばしば代謝に喩えられる。

```text
生きた構造               ─ SILN
環境との相互作用         ─ RIB
有限に取得される作用断面 ─ RIB_B
現在の身体               ─ M_B
探索・消化               ─ 展開
品質検査・選別           ─ 検査・選別
血肉化                   ─ 再構成
```

ただし比喩は定義ではない。特に **SILN = 食材** とはしない。SILN は基底構造であり、自己側も外部対象も必要に応じて対象化できる。

## 8. 再ループ
再構成された $M_B'$ も有限であり $\xi$ を伴う。

後続 `RIB_B'` との不整合が増えれば、B、Probe、Selection、候補構造のいずれかを再対象化し、必要なら ΔB を行って展開へ戻る。

この再ループは無限に同じ処理を回すという意味ではなく、**必要なとき形成経路へ戻れること**を意味する。

## 9. 一文圧縮
> **T1 は、対象化された SILN と有限な `RIB_B`・履歴・差異から候補構造を展開し、条件に耐える関係を検査・選別し、それを新しい $M_B'$ として再構成して後続相互作用へ戻す三相サイクルである。**
