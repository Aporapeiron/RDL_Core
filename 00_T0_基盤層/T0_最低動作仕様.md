## ■ 0. 位置づけ

本文書は、関係力学言語（RDL）の**中核計算・動作仕様（SPEC）**を定める。
理由の説得や哲学的背景は記述せず、定義・変数・機能要件・標準モデル・制約・状態遷移を規定する。

本仕様は、T0/T1 間での過度な概念分散を避け、RDL の基本動態を一望可能にするため、**「Core Requirement（必須要件）」** と **「Standard Model（標準動作モデル）」** の文書内二層構造を採用する。

原則：
> **最低限必要な機能と、RDL で標準的に使用する具体モデルを同一 SPEC 内に保持する。ただし両者を同一視しない。**

---

# ■ 1. T0 SPEC の二層構造

```text
T0_最低動作仕様
│
├─ Core Requirement（必須要件）
│   RDL として最低限保持する必要がある機能・制約・抽象関係
│
└─ Standard Model（標準動作モデル）
    Core Requirement を実現する標準的な記述・数式・相状態・局所近似モデル
```

- **Core Requirement**：RDL の最低動作を規定する。特定の具象数式には依存しない。
- **Standard Model**：「RDL では通常これを使う」という標準形を示す。同等の機能を満たす別モデル（離散・確率・ニューラル等）への置換を許容する（■13 差替規約）。

---

# ■ 2. 中核量（Core Primitives）

最低動作を構成する主要量を次とする。

```text
B       : 有限境界（Boundary）
ξ       : 未回収関係・揺らぎ（Residual Relation）
M_B     : 整合慣性（Consistency Inertia）
EFP     : 素流圧（Elementary Flux Pressure）
F       : 作用解釈（Flux Interpretation）
E       : 慣性誤差（Inertial Error）
H       : 熱・誤差蓄積（Accumulated Heat）
θ       : 判定境界（Decision Boundary / Threshold）
```

---

## 2.1 B ― 有限境界

```text
B : 観測・認識・記述・操作を行うための有限な選択枠組み
```

$B$ は必要に応じて以下を含みうる。

```text
B may include {
  対象（何を見るか）,
  尺度・解像度（どの粗さで見るか）,
  語彙・ラベル（どの記号で扱うか）,
  差異の選択（何と何を分けるか）,
  評価関数・用途（何のために引くか）,
  観測者（誰が引いているか ※観測者自身も M_{B_obs}）,
  必要に応じた空間・時間スケール,
  ...
}
```

※ 空間・時間は $B$ の必須構成要素ではない（道具的選択肢）。

---

## 2.2 ξ ― 未回収関係

```text
ξ : 有限境界 B を持つことに伴う未回収関係・残差
```

基底規則：

```text
[B-ξ]

∀B_finite:
  ξ(B) ≠ 0
```

すべての $B$ 依存構造は、特記がなくても $\xi$ を暗黙継承する。

---

## 2.3 M_B ― 整合慣性

```text
M_B : 境界 B のもとで一時的に安定し、入力に対する解釈・予測・応答を形成する関係構造
```

$M_B$ は現在の境界 $B$ の内部で保持されている自己の整合構造（操作表現・身体）である。
有限境界 $B$ のもとで安定し、ひとまとまりの操作対象として切り出された構造の身分（食材）を **SILN** と呼ぶ。

---

## 2.4 EFP ― 素流圧

```text
EFP : M_B へ作用する未解釈の作用束
```

$EFP$ そのものを直接取得できるとは規定しない。
RDL では、$EFP$ が $M_B$ を通して解釈された結果として $F$ を扱う。

---

## 2.5 F ― 作用解釈

```text
F : EFP が M_B を通して解釈された作用情報
```

標準表記：

```text
F = interp(M_B, EFP)
```

---

## 2.6 E ― 慣性誤差

```text
E : 既存 M_B による予期・慣性投影と、新たに得られた F との差異
```

$E$ の最低要件は、**「差異を検出できること」**である。具体的な計算法は一意に固定しない。

---

## 2.7 H ― 熱・誤差蓄積

```text
H : E が時間的・構造的に残存・蓄積・伝播した状態
```

$H$ の最低要件は、**「瞬間的な差異 E と、継続的・構造的な不整合を区別できること」**である。
具体的な積分方法・減衰方法・ノルム等は一意に固定しない。

---

## 2.8 θ ― 判定境界

```text
θ : 現在の M_B を維持する更新と、構造再編へ移行する更新を分ける判定境界
```

何を $\theta$ として採用するかは、$B$ および対象モデルに依存する。
したがって、**「$\theta$ の存在」**は動態上の基本概念として保持するが、**「$\theta$ の具体的算出法」**は固定しない。

---

# ■ 3. 最低動作関係

※ 以下の動態は主として自己側 $M_B$（身体）の更新を記述する。対象側として切り出された構造は SILN（食材）として T1 代謝操作へ渡される。

RDL の自己身体における基本的な動態を以下の一連の流れとして扱う。

```text
EFP（外部作用）
  ↓ M_B による解釈
F（作用解釈）
  ↓ 既存構造との差異
E（慣性誤差）
  ↓ 残存・蓄積・伝播
H（熱）
  ↓ θ との関係による更新判定
M_B'（更新・再編）
```

圧縮：

```text
EFP → F → E → H → θ → Update(M_B)
```

※ 全過程は有限境界 $B$ のもとで成立し、$\xi$ を暗黙継承する。

---

# ■ 4. Core Requirement（必須機能要件）

T0 として必須なのは、特定の数式ではなく以下の機能関係である。

```text
[C1] 有限境界 B を設定できる。
[C2] すべての B 依存構造（M_B, SILN, M_B' 等）は ξ を残存・暗黙継承する（[B-ξ]）。
[C3] M_B は作用 EFP を F として解釈できる。
[C4] 新しい F と既存 M_B との不整合を E として扱える。
[C5] E の残存・蓄積状態を H として扱える。
[C6] H その他の状態から、維持と再編を分ける判定境界 θ を置ける。
[C7] 判定結果に応じて M_B を更新できる。
[C8] 更新後の M_B' も B 依存であり ξ を継承する。
[C9] RDL 自身も同じ操作対象となる（[SELF]）。
```

---

# ■ 5. 最小更新則

最低仕様では、更新を抽象的に次のように記述する。

```text
M_B' = Update(M_B, F, E, H, θ, ξ)
```

または、

```text
ΔM_B = U(M_B, F, E, H, θ, ξ)
```

この抽象形式は、連続時間更新、離散時間更新、確率更新、イベント駆動、状態遷移、ニューラル更新などを排除しない。

---

# ■ 6. 標準動態モデル（Standard Dynamics Model）

T0 SPEC 内には、最低要件とは区別して標準モデルも保持する。

### 6.1 標準 F

```text
F(t) = interp(M_B, EFP)
```

### 6.2 標準 E

```text
E(t) = F(t+Δ) - M_B·F(t)
```

これは $E$ の標準的な計算形であり、唯一の定義形式とはしない。

### 6.3 標準 H

```text
H = ||H_vec||
H_vec ≡ δM_B(t)
```

または $E$ の時系列積分・蓄積として扱う。蓄積則は対象に応じて置換可能とする。

### 6.4 標準更新

```text
dM_B/dt = f(M_B, E, ξ)
```

連続時間モデルを採用する場合の標準形とする。

---

# ■ 7. θ と θ_eff

$\theta$ は判定境界の一般概念として保持する。
標準モデルの一例として、以下を使用できる。

```text
θ_eff(t) = θ + g(ξ(t))
```

ただし、$\theta_{\text{eff}} = \theta + g(\xi)$ そのものを RDL 最低仕様とはしない。
必要なのは、`TransitionCondition(...)` によって構造維持と構造再編を区別できることである。

---

# ■ 8. 整合／再編

標準動態では以下を採用できる。

```text
H < θ  ──→  M_B を維持しながら局所更新（整合モード）
H ≥ θ  ──→  M_B の再編（跳躍モード）
```

より一般には、`TransitionCondition(M_B, F, E, H, ξ, B)` に応じて、

```text
M_B → M_Δ → M_B'
```

へ遷移する。

---

# ■ 9. 相状態

以下は標準状態語彙として保持する。

```text
M_act : 活性相（現在強く機能している断面）
M_lat : 潜在相（発現していない未拘束断面）
M_Δ   : 再編相（変化の途中の不安定断面）
M_B'  : 再編後の新安定相
```

ただし、これらの状態分割そのものを唯一の分解法とはしない。最低仕様として要求するのは「維持状態」「更新状態」「再編状態」等を区別可能であることまでとする。

---

# ■ 10. 𝒦 ― 関係保存量

$\mathcal{K}$ は Core Primitive とはしない。ただし、RDL の標準局所モデルとして同一 SPEC 内に保持する。

```text
𝒦 : 境界 B の内部で、対象とする変化範囲において局所的・近似的に不変とみなされる関係量
```

標準保存近似：

```text
||M_B|| · D[ξ] = 𝒦
```

位置づけ：

```text
[B-ξ]                 ── 基底規則（仕様上の前提）
𝒦                     ── 局所不変量を置く場合の標準モデル
||M_B|| · D[ξ] = 𝒦    ── その具体的近似形式
```

したがって、$\xi$ 残存性を $\mathcal{K}$ から導出しない（因果の単一化）。

---

# ■ 11. 𝒦 を T0 SPEC 内に残す理由

$\mathcal{K}$ は最低動作に必須ではない。
しかし、$M_B$、$\xi$、安定、変化、保存の関係を扱う標準モデルとして Core 動態と密接であり、T1 へ完全分離すると基本構造の参照が分散する。

したがって、**「必須ではないが、標準モデルとして近いもの」**については T0 SPEC 内への同居を許容する。
これは $\mathcal{K}$ に限らず、標準 $E$ 式、標準 $H$ 式、$\theta_{\text{eff}}$、相状態、標準保存則にも適用する。

---

# ■ 12. T0 / T1 境界規約

Tier 境界は概念を物理的に完全分離するためのものではなく、責務を整理するために使用する。

```text
T0:
RDL の基本動作を一通り理解・実行できる最低要件と標準モデルを保持する。

T1:
T0 の構造に対して、具体的な分解・測定・破壊・翻訳・接続・再構成を行う。
また必要に応じて標準モデルを差し替える。
```

したがって、「$E$ は T0、$E$ 式は T1」「$H$ は T0、$H$ 式は T1」「$\theta$ は T0、$\theta_{\text{eff}}$ は T1」「$\mathcal{K}$ 概念は T0、保存式は T1」のような過度な分散は原則として行わない。
代わりに、**「T0 内部で 必須核 / 標準モデル を区別する」**。

---

# ■ 13. 標準モデル差替規約

T0 に記載された標準モデルは、同等以上の機能を保持する場合に差替可能とする。

```text
Standard Model  ──【SILN操作 / 翻訳 / 借用】──→  Alternative Model
```

差替時には最低限、以下を明示する。

```text
・何を E（差異）としたか
・何を H（蓄積）としたか
・何を θ（判定境界）としたか
・何を更新条件としたか
・何を保存量として扱ったか
```

---

# ■ 14. 全体構造

```text
Relational Network（非線形関係ネットワーク）
   ├─ finite B ──→ 切り出された関係構造 ＋ ξ
   │                 ├─ 自己側 ──→ M_B（自己身体：整合慣性）
   │                 └─ 対象側 ──→ SILN（操作対象・食材 ──→ T1 代謝へ）
   │                                 │
   └─ 作用束   ──────────────→ EFP（外部素流圧）
                                     │
                                     ↓ interp(M_B, EFP)
                                    F（作用解釈）
                                     │
                                     ↓ difference with inertia
                                    E（慣性誤差）
                                     │
                                     ↓ accumulation / propagation
                                    H（熱）
                                     │
                                     ↓ judgment by θ
                                    ├─ 維持・局所更新（整合相）
                                    └─ 再編（跳躍相: M_Δ）
                                        │
                                        ↓
                                       M_B' + ξ'（更新された自己身体）
```

標準局所モデルとして必要に応じて、$\theta_{\text{eff}}, \mathcal{K}, M_{\text{act}}, M_{\text{lat}}, M_\Delta$ を使用する。

# ■ 15. 一文圧縮

> **RDL 最低動作仕様は、有限境界 $B$ と $\xi$ 残存のもとで、整合慣性 $M_B$ が $EFP$ を $F$ として解釈し、既存構造との差異 $E$ とその蓄積 $H$ を受け取り、判定境界 $\theta$ に応じて $M_B$ を維持または再編する自己身体の動態機能を中核とする。$E$ / $H$ / $\theta$ 等の具体的数式、相状態、局所保存量 $\mathcal{K}$ は標準モデルとして同一 SPEC 内に保持するが、同等機能を満たす別モデルへの置換を許容する。**
