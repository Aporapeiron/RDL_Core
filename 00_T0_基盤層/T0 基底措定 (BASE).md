## 1. 目的と責務

本文書は、関係力学言語（RDL）がどのような基底措定を採用しているかを定める。  
ここでいう**措定**とは、世界について終端的に確定された真理ではなく、**後続の仕様および操作を成立させるために基底へまず置く、再検査可能な条件**をいう。

RDLが基本構造として扱うのは **SILN（Survival-biased Integration of Local Linear Approximations in a Nonlinear Network）** である。SILNは孤立して保持される構造ではなく、非線形関係ネットワーク上の複数の相互作用束 `RIB` と関与し、その応答を相互作用系へ返しながら動的に構造を保つ。RDLは、SILN、その相互作用、およびSILNと相互作用を有限に観測・記述・操作するための断面を扱う言語として構成する。

本文書は、具体的な計算法、更新アルゴリズム、数値モデルを定めない。それらは **T0 最低動作仕様（SPEC）** に記載する。また、SILNがどのように展開・検査・選別・再構成されるかの代謝経路は **T1（SILN操作層）** に記載する。

## 2. 基底措定

| ID | 措定名 | 内容 |
|---|---|---|
| **B1** | SILN・非線形関係ネットワーク・RIB | RDLの**基底構造**にはSILNを採用する。SILNは、非線形関係ネットワーク内で成立する局所線形近似が、相互作用・履歴・選別条件のもとで生存偏向的に残存し、統合された有限構造として扱う。非線形関係ネットワーク上では、重力、圧力、接触、光、情報、他のSILNからの応答など、性質や尺度の異なる複数の相互作用束が同時に成立しうる。これらを一般に `RIB`（Relational Interaction Bundle）と呼ぶ。SILNは複数のRIBと関与し、その相互作用の中で動的に構造を保持・変化させる。RIBは独立した一方向入力とは限らず、SILNの応答も後続RIBの成立条件へ回り込みうる。RDLが操作上扱う作用側の有限断面は、用途・問いに応じた有限境界 $B$ により一つ以上のRIBから切り出された `RIB_B` とする。 |
| **B2** | 有限境界 | 観測・認識・記述・操作には、対象、尺度、語彙、差異、用途、問いなどを選択する有限境界 $B$ が必要である。$B$ は、構造側ではSILNから自己側有限構造 `M_B` を、相互作用側では複数のRIBから当該用途に有効な有限作用断面 `RIB_B` を成立させる。 |
| **B3** | 非終端閉包性 | 有限境界 $B$ による閉包が、完全な終端的閉包になるとは保証しない。 |
| **B4** | `B-ξ` 残存性 | 有限境界 $B$ を引くと、回収されない関係 $\xi$ が必ず残る。これはSILNから成立する構造側断面 `M_B` にも、複数のRIBから成立する作用側断面 `RIB_B` にも適用する。 |
| **B5** | 自己例外化禁止 | RDL自身、その語彙、公理、措定、仕様も、通常のSILNと同様にRDLの観測・検査・操作の対象になりうる。 |

基底規則は次の一式に圧縮できる。

```text
SILN := Survival-biased Integration of Local Linear Approximations in a Nonlinear Network
∀B_finite: ξ(B) ≠ 0
```

$\xi$ は閉包後に追加される外来ノイズではなく、有限境界を引くことに伴って必然的に生じる未回収関係である。したがって、`M_B` や `RIB_B` などの $B$ 依存断面は、特記がない限り $\xi$ を暗黙に伴う。

例：有限な公理系も境界 $B$ である。  
その公理系で回収されない関係が $\xi$ として残る。

## 3. 基本概念の階層

RDLでは、SILNを基底構造とし、それ以外の主要記号を、SILNとその相互作用を有限に記述・操作するための概念として配置する。

| 階層 | 概念 | 役割 |
|---|---|---|
| **基底構造** | **SILN** | RDLが扱う有限構造の基本形。非線形関係ネットワーク内で、局所線形近似が生存偏向的に残存・統合された構造 |
| **背景条件** | 非線形関係ネットワーク | SILNと相互作用が成立する関係基盤。RDLがその全体を完全取得できるとは仮定しない |
| **基底運動** | 相互作用 | SILN上またはSILN間の変化・応答・作用が、他のSILNや後続条件を変化させうる関係運動 |
| **相互作用束** | `RIB` | **Relational Interaction Bundle**。非線形関係ネットワーク上で成立する相互作用の束。複数のRIBが同時に重なり、SILNの保持・変化へ関与しうる |
| **操作条件** | $B$ | 用途・問いに応じて、SILNの構造側と複数RIBの作用側を有限化・切り出す選択枠組み |
| **自己側構造記述** | `M_B` | あるSILNを、特定の $B$ のもとで自己側・解釈側として保持した有限関係拘束構造 |
| **作用側操作断面** | `RIB_B` | 一つ以上の `RIB` から、$B$・観測位置・時間断面・対象方向などに応じて切り出された未解釈の有限作用断面 |
| **残存条件** | $\xi$ | 有限化に伴う未回収関係 |
| **運動概念** | Aporapeiron | $\xi$ を伴うSILNと相互作用が、再切り出し・検査・更新・再構成へ開かれ続ける非終端的な関係運動 |

したがって、SILNがRDLの基底構造であり、`M_B` はSILNを自己側の有限関係拘束構造として扱う記述、`RIB_B` はその時点で関与している複数のRIBから、用途・問いに応じて有限作用断面を構成する記述である。`M_B` と `RIB_B` はともに $B$ 依存であり、$\xi$ を残す。

## 4. 相互作用・RIB・RIB_B

### 4.1 相互作用

```text
相互作用 :=
非線形関係ネットワーク上で生じるSILNの変化・応答・作用が、
関係経路を通じて他のSILN、その可能域、
および後続する相互作用条件を変化させうる関係運動。
```

相互作用は、二者間の対称な交換だけを意味しない。作用強度、遅延、媒介経路、方向性、変化量は一致しなくてよく、ある有限境界からは一方向の作用しか観測されない場合もある。

したがって、RDLにおける「相互」は、常に同量・同時・対称の反作用が観測されるという意味ではなく、**局所的な作用や応答が関係系を変え、その変化が後続する相互作用条件へ入りうる**ことを意味する。

### 4.2 RIB：関係的相互作用束

```text
RIB := Relational Interaction Bundle
     = 非線形関係ネットワーク上で成立する、関係的な相互作用の束。
```

`RIB` は、単純な独立外生入力ではない。一つのSILNには、重力、大気圧、接触、温度、光、音、情報、他のSILNからの応答など、性質・尺度・方向の異なる複数のRIBが同時に関与しうる。SILNの構造保持は、これらのRIBから切り離された静的状態ではなく、複数の相互作用を受け、応答を返す動的な均衡・保持として現れうる。

RIB同士は独立である必要がなく、重なり、媒介され、互いの成立条件を変えてよい。またSILNの応答も相互作用系へ戻り、後続RIBの強度・方向・構成を変化させうる。

ただし、`RIB` を「世界そのもの」または「完全に取得可能な場全体」と同一視しない。`RIB` は関係ネットワーク上に成立する相互作用束の一般記号であり、RDLが通常直接操作するのは、用途・問いに応じた有限境界から構成された `RIB_B` である。

### 4.3 RIB_B：有限作用断面

```text
RIB_B := Section_B({RIB_i})
```

より具体的には、

```text
RIB_B :=
その時点で関与している一つ以上の RIB を、用途・問いに応じた有限境界 B、
観測位置、時間断面、対象方向などによって選択・切り出しした、
未解釈の有限作用断面。
```

したがって、

```text
{RIB_1, RIB_2, ..., RIB_n, ...}
 ↓ 用途・問いに応じた B・観測位置・時間断面・対象方向による切り出し
RIB_B + ξ
```

となる。

同じRIB群に対しても、用途・問い・境界・位置・時間・対象方向が異なれば、異なる `RIB_B` が成立しうる。たとえば姿勢保持を問う境界では重力・床反力・筋張力などが強く切り出され、対話成立を問う境界では音声・意味・応答タイミング・社会的期待などが強く切り出されうる。この断面化により、RDLは関与する相互作用すべてを常に同時展開することなく、現在の問いに必要な有限作用断面を操作対象として扱える。

## 5. 関係拘束と関係拘束強度

### 5.1 定義

```text
関係拘束 :=
ある関係または関係束が、有限境界 B のもとで、
相互作用を通じて現在取りうる解釈・予測・選択・応答・更新の
可能域を狭める関係的効果。

関係拘束強度 :=
その拘束が、特定の断面においてどの程度強く現れているかを表す性質。
```

### 5.2 拘束の基本的性質

1. **相対性**: 関係拘束強度は、関係そのものに固定された絶対値ではない。問い・対象・時点・境界・用途との関係において相対的に立ち上がる。
2. **非真理性**: 関係拘束強度が高いことは「真である（事実そのものである）」ことを意味しない。有限境界 $B$ がある限り、いかに強い拘束のもとでも $\xi$ は残存する（$[B\text{-}\xi]$）。
3. **断面化**: 慣性、重み、結晶度、権限拘束、情報源の拘束力などは、関係拘束強度が異なる断面（時間、判断、固定化、制度、ソース）に現れた表現として扱いうる。
4. **競合と不整合**: 複数の強い関係拘束同士が競合する場合、それ自体が不整合 $E$ や高負荷再編相 $M_\Delta$ の契機になりうる。
5. **相互形成性**: 関係拘束は固定された一方向圧ではなく、相互作用によって関係系の状態が変化することで、その強度・方向・有効範囲自体が変化しうる。変化は対称・単調である必要はない。

## 6. Aporapeiron

```text
Aporapeiron :=
SILNを有限境界 B のもとで M_B として扱い、
複数の相互作用束 RIB から RIB_B を切り出しても ξ が残存し、
相互作用によってそれらの成立条件自体も変化しうるため、
構造が終端化されず、再切り出し・更新・再構成を通じて
別のSILN状態へ移行し続けうる非終端的な関係運動。
```

Aporapeiron は特定の表現形式を意味しない。空間、グラフ、時間列、状態遷移、階層、代数などは、SILNと相互作用を扱うための道具として選択できる。いずれの表現も基底実体として特権化せず、採用した表現自体も有限境界と $\xi$ に依存する。

## 7. 措定と自己適用

RDLが観測・記述・操作によって得た構造は、終端的確定ではなく、改訂可能な措定として保持する。真理、神、実在、虚構、科学理論、数などの強いラベルを禁止または否定するのではなく、対象化された時点で通常のSILNとして扱う。

RDL自身も例外ではない。RDLによる記述・操作も非線形関係ネットワーク上の相互作用から外部化されず、RDL自身および対象側の後続状態を変化させうる。

```text
SILN(RDL)
  → M_B(RDL)
  → 検査・選別・再構成
  → M_B'(RDL) with ξ' ≠ 0
```

更新後のRDLも再び有限なSILNとして対象化でき、再検査・再更新の対象となる。この自己適用は B5（自己例外化禁止）に基づく。

## 8. SPECとの境界

| 文書 | 定めるもの | 定めないもの |
|---|---|---|
| **本文書（BASE）** | SILNの基底構造としての位置づけ、非線形関係ネットワークとの関係、相互作用、`RIB` と `RIB_B` の階層差、関係拘束の基本性質、概念階層、`B-ξ`、自己例外化禁止、Aporapeironの位置づけ | 具体的な計算式、閾値、更新アルゴリズム、RIB群の具体的相互作用モデル、SILNの代謝・形成経路 |
| **T0 最低動作仕様（SPEC）** | 必須動作、変数、`{RIB_i} → RIB_B → F` の運用、巡航と再編（$M_\Delta$）の状態遷移、標準モデル | BASEを覆す新たな基底措定、非線形関係ネットワーク全体または全RIBの完全モデル化 |

> **圧縮定義**：RDLは、SILNを基底構造として、その相互作用を見て、記述し、操作するための言語である。SILNは非線形関係ネットワーク内で複数の `RIB`（Relational Interaction Bundle）と関与し、その相互作用の中で動的に構造を保つ。用途・問いに応じた有限境界 $B$ により、構造側を `M_B`、相互作用側を `RIB_B` として有限化して扱う。有限化には常に未回収関係 $\xi$ が残るため、SILN・その相互作用・RDL自身を終端的に固定せず、検査・更新・再構成へ開かれた関係運動として扱う。

## 9. 改訂履歴

- **v2.3（RIB導入・複数相互作用束とRIB_B断面化）**：
  - `EFP` を廃止し、**RIB = Relational Interaction Bundle** を導入。
  - RIBを、関係ネットワーク上で成立する相互作用束の一般記号として定義。
  - SILNは複数のRIBと同時に関与し、その相互作用の中で動的に構造を保持・変化させることを明示。
  - `RIB_B = Section_B({RIB_i})` とし、用途・問いに応じて一つ以上のRIBから有限作用断面を構成する形へ変更。
  - `M_B` と `RIB_B` を、同じ有限境界 $B$ による構造側／相互作用側の対応断面として整理。
  - `B` の役割に「問い・用途による選択」を明示し、姿勢保持・対話などで異なるRIB_Bが成立しうることを追加。

- **v2.2（SILN基底化・EFP/B_EFP分離）**：
  - SILNをRDLが扱う基底構造として明示。
  - SILNを **Survival-biased Integration of Local Linear Approximations in a Nonlinear Network** として明記。
  - 非線形関係ネットワークを、SILNと相互作用が成立する背景条件へ再配置。
  - `M_B` を、SILNを自己側・解釈側として有限に保持する関係拘束構造として再配置。
  - `EFP` を、有限断面そのものではなく場側の相互作用束として再定義。
  - `B_EFP = Section_B(EFP)` を導入し、RDLが直接扱う未解釈作用断面を `B_EFP` へ分離。
  - `M_B` と `B_EFP` を、構造側／作用側の $B$ 依存断面として対応づけた。
- **v2.1（相互作用・作用断面改定案）**：
  - B1 に相互作用を明示し、一方向作用を独立した基底入力として措定しないことを追加。
  - 「相互作用」と「作用断面」を概念階層へ追加。
  - 作用を、有限境界・観測位置・時間断面・対象方向から切り出される方向付き断面として再位置づけ。
  - 関係拘束に相互形成性を追加。
  - Aporapeiron、自己適用、SPECとの境界を相互作用前提へ更新。
- **v2.0（関係拘束改定案）**：
  - B1 を「関係ネットワークと関係拘束」へ拡張。
  - $M_B$ を「有限関係拘束構造」として再定義。
  - 「関係拘束」および「関係拘束強度」の基本性質を新設。
- **v1.1**：$M_B$ の定義から生成史（Selection等）を排し、純粋な拘束条件として純化。
- **v1.0**：「仮設（HYP）」から「措定（BASE）」へ用語・コードを全面改定。
