# T0 基底仮設（HYP）

*RDL基盤層 / HYP / 整理版 v0.8*

## 1. 目的と責務

本文書は、関係力学言語（RDL）がどのような前提を採用しているかを定める。ここでいう前提は、世界の最終的な真理を証明するものではなく、後続の仕様および操作が依存する基底条件を明示するためのものである。

本文書は、具体的な計算法、更新アルゴリズム、数値モデルを定めない。それらは **T0 最低動作仕様（SPEC）** に記載する。

## 2. 基底仮設

| ID | 仮設 | 内容 |
|---|---|---|
| H1 | 関係ネットワーク | 基底記述には、孤立した実体ではなく、相互接続された非線形関係ネットワークを採用する。 |
| H2 | 有限境界 | 観測・認識・記述・操作には、対象、尺度、語彙、差異、用途などを選択する有限境界 `B` が必要である。 |
| H3 | 非終端閉包性 | 有限境界 `B` による閉包が、完全な終端的閉包になるとは保証しない。 |
| H4 | `B-ξ` 残存性 | 有限境界 `B` を引くと、回収されない関係 `ξ` が残る。 |
| H5 | 自己例外化禁止 | RDL自身、その語彙、公理、仕様も、RDLの観測・検査・操作の対象になりうる。 |

基底規則は次の一式に圧縮できる。

```text
∀B_finite: ξ(B) ≠ 0
```

`ξ` は閉包後に追加されるノイズではなく、有限境界を引くことに伴って生じる未回収関係である。また、`B` に依存する構造は、特記がない限り `ξ` を暗黙に伴う。

## 3. 基本概念の階層

RDLでは、次の概念を同一階層の要素として扱わない。

| 階層 | 概念 | 役割 |
|---|---|---|
| 基底 | 関係ネットワーク | あらゆる構造の基底記述 |
| 操作条件 | `B` | 有限化・切り出しを行う選択枠組み |
| 残存条件 | `ξ` | 有限化に伴う未回収関係 |
| 有限構造 | `M_B` | 自己側が保持する一時的な整合構造・身体 |
| 有限構造 | SILN | 対象側へ切り出された操作対象構造・食材 |
| 運動概念 | Aporapeiron | `ξ`を伴う有限構造が、再切り出し・検査・更新・再構成へ開かれ続ける非終端的な関係運動 |

したがって、`M_B` と SILN は有限構造であり、`ξ` はその有限化に伴う残存条件である。Aporapeironは、それらが変化し続ける運動全体を指す。

## 4. Aporapeiron

```text
Aporapeiron :=
有限境界 B によって有限構造が成立しても ξ が残存し、
その構造が終端化されず、再切り出し・更新・再構成を通じて
別の有限構造へ移行し続けうる非終端的な関係運動。
```

Aporapeironは特定の表現形式を意味しない。空間、グラフ、時間列、状態遷移、階層、代数などは、有限構造を扱うための道具として選択できる。いずれの表現も基底実体として特権化せず、採用した表現自体も有限境界と`ξ`に依存する。

## 5. 仮設と自己適用

RDLが観測・記述・操作によって得た構造は、終端的確定ではなく仮設として保持する。真理、神、実在、虚構、科学理論、数などの強いラベルを禁止または否定するのではなく、対象化された時点で通常の有限構造として扱う。

RDL自身も例外ではない。

```text
M_B(RDL)
  → SILN_SELF(RDL)
  → 検査・選別・再構成
  → M_B'(RDL) + ξ
```

更新後のRDLも再び有限構造であり、再対象化・再検査・再更新の対象となる。この自己適用はH5に基づく。

## 6. SPECとの境界

| 文書 | 定めるもの | 定めないもの |
|---|---|---|
| 本文書（HYP） | 基底仮設、概念階層、`B-ξ`、自己例外化禁止、Aporapeironの位置づけ | 具体的な計算式、閾値、更新アルゴリズム |
| T0 最低動作仕様（SPEC） | 必須動作、変数、状態遷移、標準モデル、モデル差替条件 | HYPを覆す新たな基底仮設 |

> **圧縮定義**：RDLは、関係ネットワークに有限境界`B`を引くと、有限構造とともに未回収関係`ξ`が残ると仮設する。したがって、構造とRDL自身を終端的に固定せず、検査・更新・再構成へ開かれた関係運動として扱う。
