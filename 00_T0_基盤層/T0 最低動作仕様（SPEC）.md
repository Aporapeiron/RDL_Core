# T0 最低動作仕様（SPEC）

*RDL基盤層 / SPEC / 整理版 v0.8*

## 1. 目的と適用範囲

本文書は、RDLが最低限実行できなければならない中核動作を定める。基底となる考え方は **T0 基底仮設（HYP）** に依存する。本仕様では、哲学的な理由づけを繰り返さず、動作上必要な定義・機能要件・状態遷移を記述する。

### 1.1 認識上の前提

RDLは、世界そのものを直接記述または取得するとは仮定しない。RDLが直接に扱うのは、有限境界`B`を通じて形成された**抽象化された解釈・予測**と、それらの後続的な差異である。

この前提により、`EFP`も世界そのものではなく、RDLの境界内で作用として扱われる未解釈の作用束を意味する。また、`F`と`F'`は世界の状態そのものではなく、同じ更新前の`M_B`が異なる入力から形成した解釈状態である。したがって、`E`は世界そのものと内部表象との差ではなく、解釈・予測の間に検出される不整合として扱う。

> **RDLにとって、直接に扱えるのは世界そのものではなく、有限境界`B`を通じて形成された解釈である。**

本仕様は次の二層で構成する。

| 層 | 役割 | 置換可能性 |
|---|---|---|
| Core Requirement | RDLとして最低限必要な抽象機能 | 満たすべき機能を変更しない |
| Standard Model | Core Requirementを実現する標準的な式・状態・局所モデル | 同等以上の機能を満たすモデルへ置換できる |

## 2. 中核変数

| 記号 | 名称 | 最低限の意味 |
|---|---|---|
| `B` | 有限境界 | 観測・認識・記述・操作のための有限な選択枠組み |
| `ξ` | 未回収関係 | 有限境界に伴って残る関係 |
| `M_B` | 整合慣性 | `B`のもとで一時的に安定し、解釈・予測・応答を形成する自己側構造 |
| `SILN` | 操作対象構造 | `B`のもとで切り出された対象側の有限構造 |
| `EFP` | 素流圧 | `B`の内部で作用として扱われる、`M_B`へ作用する未解釈の作用束 |
| `F` | 作用解釈・予測 | `EFP`が`M_B`を通して解釈され、現在構造から形成された作用情報・予測 |
| `F'` | 後続作用解釈 | 後続する`EFP'`を、更新前の同じ`M_B`が解釈して形成した次の作用情報 |
| `E` | 慣性誤差 | `F`が含む予測と、後続して形成された`F'`との差異 |
| `H` | 熱・誤差蓄積 | `E`のうち、現在構造で吸収・解消されず、残存・蓄積・伝播した状態 |
| `θ` | 判定境界 | 構造維持と構造再編を分ける判定条件 |

`B`依存構造（`M_B`、SILN、更新後の`M_B'`など）は、HYPの`[B-ξ]`に従い、特記がなくても`ξ`を伴う。

## 3. Core Requirement

RDLの最低動作は、以下の機能を満たさなければならない。

| ID | 必須機能 |
|---|---|
| C1 | 有限境界`B`を設定できる。 |
| C2 | `B`依存構造に`ξ`残存を付与・継承できる。 |
| C3 | `M_B`が作用`EFP`を`F`として解釈し、予測を形成できる。 |
| C4 | 現在構造から形成された予測`F`と、後続入力から形成された`F'`との差異を`E`として扱える。 |
| C5 | `E`のうち吸収・解消されない残存・蓄積・伝播を`H`として扱える。 |
| C6 | `H`その他の状態から、維持と再編を分ける`θ`を設定できる。 |
| C7 | 判定結果に応じて、`M_B`を維持または更新できる。 |
| C8 | 更新後の`M_B'`も`B`依存であり、`ξ`を継承する。 |
| C9 | RDL自身を通常の操作対象として扱える。 |

## 4. 最低動作フロー

自己側の基本動作は、現在構造による予測と、後続入力を同じ更新前構造で解釈した結果との差異として記述する。

```text
EFP
 ↓ M_Bによる解釈・予測
F
 │
 │ 後続入力
 ↓
EFP'
 ↓ 同一の更新前M_Bによる解釈
F'
 ↓ Fとの予測差異
E
 ↓ 吸収・解消されない差異の残存・蓄積・伝播
H
 ↓ θによる判定
維持・局所更新 または 再編
 ↓
M_B'
```

圧縮表記は次のとおりである。

```text
EFP → F
         \\
          Δ(F,F') → E → H → θ → Update(M_B)
         /
EFP' → F'
```

`F'`の形成には、更新後の`M_B'`ではなく、更新前の同一の`M_B`を用いる。

対象側の有限構造はSILNとして切り出され、必要に応じてT1の分解・測定・翻訳・接続・再構成へ渡される。

## 5. 抽象更新則

具体的な時間形式やアルゴリズムは固定しない。最低限、更新は次の抽象形式で表現できなければならない。

```text
M_B' = Update(M_B, F, E, H, θ, ξ)
```

または、差分形式として次を用いてよい。

```text
ΔM_B = U(M_B, F, E, H, θ, ξ)
```

連続時間、離散時間、確率的更新、イベント駆動、状態遷移、ニューラル更新などは、C1〜C9を満たす限り排除しない。

## 6. Standard Model

以下は必須定義ではなく、RDLで使用する標準的な具体化である。

### 6.1 解釈と誤差

```text
F(t)      = interp(M_B, EFP(t))
F'(t+Δ)   = interp(M_B, EFP(t+Δ))

E(t+Δ)    = Δ(F, F')
```

ここで`F`は、現在の`M_B`が形成する解釈と、それに基づく後続状態への予測を含む。`F'`は、後続する入力を更新前の同一の`M_B`が解釈して形成した作用情報であり、`M_B'`による更新後の出力を意味しない。

したがって`E`は、世界そのものと内部表象との差ではなく、現在の整合構造から形成された予測と、その後に同じ構造を通して形成された状態との差異として定義される。

`Δ`の具体的な距離、差分、損失関数、比較方法は固定しない。`E`の本質は、現在構造の予測と後続状態との不整合を検出することにある。

### 6.2 蓄積と更新

```text
H = ||H_vec||
H_vec ≡ δM_B(t)

dM_B/dt = f(M_B, E, ξ)
```

`H`は、`E`の時系列積分、蓄積、減衰、伝播などによって具体化してもよい。ノルム、積分法、減衰法は対象モデルに応じて選択する。

### 6.3 判定と相状態

標準判定の一例は次のとおりである。

```text
H < θ  → 維持・局所更新
H ≥ θ  → 再編
```

再編時には、次の遷移を用いてよい。

```text
M_B → M_Δ → M_B'
```

標準状態語彙として、`M_act`（活性相）、`M_lat`（潜在相）、`M_Δ`（再編相）、`M_B'`（再編後の安定相）を使用できる。ただし、最低限必要なのは維持・更新・再編を区別できることであり、この分割を唯一の方式とはしない。

### 6.4 任意の補助モデル

必要に応じて、`ξ`の影響を判定境界へ反映する標準形として次を使用できる。

```text
θ_eff(t) = θ + g(ξ(t))
```

また、局所的な関係保存を扱う場合は、次の`𝒦`を標準補助モデルとして導入できる。

```text
||M_B|| · D[ξ] = 𝒦
```

`𝒦`はCore Primitiveではなく、`[B-ξ]`から残存性を導出するものでもない。これは、特定の境界と変化範囲で局所的に不変とみなす関係量である。

## 7. 標準モデルの差替規約

標準モデルは、Core Requirementと同等以上の機能を保持する場合に差し替えられる。差替時には、少なくとも次の対応を明示する。

| 確認項目 | 明示する内容 |
|---|---|
| `E` | `F`による何の予測と、どの後続`F'`との何を差異として検出するか |
| `H` | 何を蓄積・残存状態として扱うか |
| `θ` | 何を維持と再編の判定境界とするか |
| 更新 | どの条件で`M_B`を更新するか |
| `ξ` | 有限境界に伴う未回収関係をどう保持するか |
| 任意量 | `𝒦`等を採用する場合、その局所的意味と範囲 |

## 8. T0 / T1の責務分担

| 層 | 責務 |
|---|---|
| T0 | RDLの基底仮設、最低動作、標準モデルを保持する。 |
| T1 | T0の構造に対する具体的な分解、測定、破断、翻訳、接続、再構成を行う。必要に応じて標準モデルを差し替える。 |

T0とT1は概念を物理的に分離する境界ではなく、責務を整理する境界である。したがって、`E`とその式、`H`とその式、`θ`と`θ_eff`を別文書へ機械的に分割せず、T0内で必須核と標準モデルを分けて保持する。

> **圧縮定義**：RDLでは、有限境界`B`と`ξ`残存のもとで、`M_B`が`EFP`を`F`として解釈・予測し、後続入力から形成された`F'`との差異を`E`として検出する。吸収されず残存する差異は`H`として蓄積・伝播し、`θ`に応じて自己構造を維持または再編する。この動作が最低仕様であり、具体的な差異計算・蓄積則・相状態・局所保存量は差替可能な標準モデルである。

## 9. 改訂履歴

- **v0.8**：世界そのものを直接扱わず、有限境界`B`のもとで形成された抽象化された解釈・予測を扱うという認識上の前提を追加。`EFP`、`F`、`F'`、`E`の対象範囲をこの前提に合わせて明確化。
- **v0.7**：`E`を現在の`M_B`が形成した予測`F`と、後続入力から同一の更新前`M_B`を通して形成された`F'`との差異として明確化。`F'`を導入し、Core Requirement・最低動作フロー・Standard Model・圧縮定義を統一。
- **v0.6**：必須変数、必須機能、動作フロー、抽象更新則、標準モデル、差替規約の順に再配置。HYPとの重複説明を削減。
- **v0.5**：`M_B`とSILNの自己側・対象側の区別、および`ξ`継承を明示。
