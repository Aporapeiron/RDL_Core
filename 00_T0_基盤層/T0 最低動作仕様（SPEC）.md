# T0 最低動作仕様（SPEC）

*RDL基盤層 / SPEC / 整理版 v0.6*

## 1. 目的と適用範囲

本文書は、RDLが最低限実行できなければならない中核動作を定める。基底となる考え方は **T0 基底仮設（HYP）** に依存する。本仕様では、哲学的な理由づけを繰り返さず、動作上必要な定義・機能要件・状態遷移を記述する。

本仕様は次の二層で構成する。

| 層 | 役割 | 置換可能性 |
|---|---|---|
| Core Requirement | RDLとして最低限必要な抽象機能 | 満たすべき機能を変更しない |
| Standard Model | Core Requirementを実現する標準的な式・状態・局所モデル | 同等以上の機能を満たすモデルへ置換できる |

## 2. 中核変数

| 記号 | 名称 | 最低限の意味 |
|---|---|---|
| `B` | 有限境界 | 観測・認識・記述・操作のための有限な選択枠組み |
| `ξ` | 未回収関係 | 有限境界に伴って残る関係 |
| `M_B` | 整合慣性 | `B`のもとで一時的に安定し、解釈・予測・応答を形成する自己側構造 |
| `SILN` | 操作対象構造 | `B`のもとで切り出された対象側の有限構造 |
| `EFP` | 素流圧 | `M_B`へ作用する未解釈の作用束 |
| `F` | 作用解釈 | `EFP`が`M_B`を通して解釈された作用情報 |
| `E` | 慣性誤差 | 既存の`M_B`による予測と、新たな`F`との差異 |
| `H` | 熱・誤差蓄積 | `E`が残存・蓄積・伝播した状態 |
| `θ` | 判定境界 | 構造維持と構造再編を分ける判定条件 |

`B`依存構造（`M_B`、SILN、更新後の`M_B'`など）は、HYPの`[B-ξ]`に従い、特記がなくても`ξ`を伴う。

## 3. Core Requirement

RDLの最低動作は、以下の機能を満たさなければならない。

| ID | 必須機能 |
|---|---|
| C1 | 有限境界`B`を設定できる。 |
| C2 | `B`依存構造に`ξ`残存を付与・継承できる。 |
| C3 | `M_B`が作用`EFP`を`F`として解釈できる。 |
| C4 | 新しい`F`と既存`M_B`との差異を`E`として扱える。 |
| C5 | `E`の残存・蓄積・伝播を`H`として扱える。 |
| C6 | `H`その他の状態から、維持と再編を分ける`θ`を設定できる。 |
| C7 | 判定結果に応じて、`M_B`を維持または更新できる。 |
| C8 | 更新後の`M_B'`も`B`依存であり、`ξ`を継承する。 |
| C9 | RDL自身を通常の操作対象として扱える。 |

## 4. 最低動作フロー

自己側の基本動作は、次の順序で記述する。

```text
EFP
 ↓ M_Bによる解釈
F
 ↓ 既存構造との差異
E
 ↓ 残存・蓄積・伝播
H
 ↓ θによる判定
維持・局所更新 または 再編
 ↓
M_B'
```

圧縮表記は次のとおりである。

```text
EFP → F → E → H → θ → Update(M_B)
```

対象側の有限構造はSILNとして切り出され、必要に応じてT1の分解・測定・翻訳・接続・再構成へ渡される。

## 5. 抽象更新則

具体的な時間形式やアルゴリズムは固定しない。最低限、更新は次の抽象形式で表現できなければならない。

```text
M_B' = Update(M_B, F, E, H, θ, ξ)
```

または、差分形式として次を用いてよい。

```text
ΔM_B = U(M_B, F, E, H, θ, ξ)
```

連続時間、離散時間、確率的更新、イベント駆動、状態遷移、ニューラル更新などは、C1〜C9を満たす限り排除しない。

## 6. Standard Model

以下は必須定義ではなく、RDLで使用する標準的な具体化である。

### 6.1 解釈と誤差

```text
F(t) = interp(M_B, EFP)
E(t) = F(t+Δ) - M_B·F(t)
```

`E`の本質は差異の検出であり、上式は標準形の一例にすぎない。

### 6.2 蓄積と更新

```text
H = ||H_vec||
H_vec ≡ δM_B(t)

dM_B/dt = f(M_B, E, ξ)
```

`H`は、`E`の時系列積分、蓄積、減衰、伝播などによって具体化してもよい。ノルム、積分法、減衰法は対象モデルに応じて選択する。

### 6.3 判定と相状態

標準判定の一例は次のとおりである。

```text
H < θ  → 維持・局所更新
H ≥ θ  → 再編
```

再編時には、次の遷移を用いてよい。

```text
M_B → M_Δ → M_B'
```

標準状態語彙として、`M_act`（活性相）、`M_lat`（潜在相）、`M_Δ`（再編相）、`M_B'`（再編後の安定相）を使用できる。ただし、最低限必要なのは維持・更新・再編を区別できることであり、この分割を唯一の方式とはしない。

### 6.4 任意の補助モデル

必要に応じて、`ξ`の影響を判定境界へ反映する標準形として次を使用できる。

```text
θ_eff(t) = θ + g(ξ(t))
```

また、局所的な関係保存を扱う場合は、次の`𝒦`を標準補助モデルとして導入できる。

```text
||M_B|| · D[ξ] = 𝒦
```

`𝒦`はCore Primitiveではなく、`[B-ξ]`から残存性を導出するものでもない。これは、特定の境界と変化範囲で局所的に不変とみなす関係量である。

## 7. 標準モデルの差替規約

標準モデルは、Core Requirementと同等以上の機能を保持する場合に差し替えられる。差替時には、少なくとも次の対応を明示する。

| 確認項目 | 明示する内容 |
|---|---|
| `E` | 何を差異として検出するか |
| `H` | 何を蓄積・残存状態として扱うか |
| `θ` | 何を維持と再編の判定境界とするか |
| 更新 | どの条件で`M_B`を更新するか |
| `ξ` | 有限境界に伴う未回収関係をどう保持するか |
| 任意量 | `𝒦`等を採用する場合、その局所的意味と範囲 |

## 8. T0 / T1の責務分担

| 層 | 責務 |
|---|---|
| T0 | RDLの基底仮設、最低動作、標準モデルを保持する。 |
| T1 | T0の構造に対する具体的な分解、測定、破断、翻訳、接続、再構成を行う。必要に応じて標準モデルを差し替える。 |

T0とT1は概念を物理的に分離する境界ではなく、責務を整理する境界である。したがって、`E`とその式、`H`とその式、`θ`と`θ_eff`を別文書へ機械的に分割せず、T0内で必須核と標準モデルを分けて保持する。

> **圧縮定義**：RDLでは、有限境界`B`と`ξ`残存のもとで、`M_B`が`EFP`を`F`として解釈し、差異`E`と蓄積`H`を受け取り、`θ`に応じて自己構造を維持または再編する。この動作が最低仕様であり、具体的な式・相状態・局所保存量は差替可能な標準モデルである。
