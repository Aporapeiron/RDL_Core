## 1. 目的と適用範囲

本文書は、RDLがSILNを扱うために最低限実行できなければならない中核動作を定める。基底となる考え方は **T0 基底措定（BASE）** に依存する。本仕様では、哲学的な理由づけを繰り返さず、動作上必要な定義・機能要件・状態遷移を記述する。

### 1.1 認識上の前提

RDLは、非線形関係ネットワーク全体、世界そのもの、またはそこに成立するすべての相互作用束を直接・完全に取得できるとは仮定しない。SILNには複数の `RIB`（Relational Interaction Bundle）が同時に関与しうる。RDLが直接の操作単位として扱うのは、用途・問いに応じた有限境界 $B$ のもとで保持されたSILNの自己側構造 `M_B`、一つ以上のRIBから構成された有限作用断面 `RIB_B`、そこから形成された**抽象化された解釈・予測**、およびそれらの後続的な差異である。

`RIB` は **Relational Interaction Bundle** の略であり、非線形関係ネットワーク上で成立する相互作用束の一般記号である。重力、大気圧、接触、光、音、情報、他のSILNからの応答など、性質・尺度・方向の異なる複数のRIBが同時に一つのSILNへ関与しうる。RIBは単純な独立外生入力ではなく、SILNの応答も後続RIBの成立条件へ回り込みうる。

`RIB_B` は、その時点で関与している一つ以上のRIBを、用途・問いに応じた有限境界 $B$・観測位置・時間断面・対象方向などから選択・切り出して構成した**未解釈の有限作用断面**である。RDLの通常運転では、関与する全RIBを展開するのではなく `RIB_B` を `M_B` が解釈する。

`F` と `F'` は世界の状態そのものではなく、同じ更新前の `M_B` が異なる時点の `RIB_B` から形成した解釈状態である。したがって、`E` は世界そのものと内部表象との差ではなく、解釈・予測の間に検出される**不整合**として扱う。

> **RDLにとって、SILNが基底構造である。SILNは複数のRIBとの相互作用の中で動的に構造を保ち、RDLは用途・問いに応じた有限境界 $B$ によって、構造側を `M_B`、相互作用側を `RIB_B` として操作する。**

### 1.2 SILN・RIB・RIB_Bの最低動作断面

BASEが基底構造に置くのはSILNである。SILNは非線形関係ネットワーク上で、複数のRIBと同時に相互作用しながら構造を保持・変化させる。最低動作では関与するRIB群全体を常に展開せず、用途・問いに応じた有限境界 $B$ により、特定の `M_B` に対して有効な有限作用断面 `RIB_B` を構成して扱う。

```text
SILN群 / 非線形関係ネットワーク上の相互作用
          ↓
{RIB_1, RIB_2, ..., RIB_n, ...}
          ↓ 用途・問いに応じた B・観測位置・時間断面・対象方向による切り出し
       RIB_B
          ↓
   interp(M_B, RIB_B)
          ↓
          F
```

各 `RIB` の成立条件は複雑でありうる。そこには、複数のSILN、他の解釈系、関係履歴、環境、媒介構造、先行する作用・応答、未回収関係 $\xi$ などが関与しうる。また複数RIBは互いに独立である必要がなく、重なりや媒介を通じて成立条件を変えあってよい。

ただし、最低動作ではこれらを毎回展開することを要求しない。通常運転では、個々のRIBの生成過程や関与するRIB群全体を畳んだまま、必要な操作断面 `RIB_B` を一つの未解釈作用断面として扱ってよい。

また、後続するRIB群は、先行するRIB群と独立した外生入力である必要はない。先行する `M_B` の解釈・選択・応答が関係系を変化させ、その変化が次のRIB群の成立条件へ回り込んでよい。

```text
RIB_B(t) → interp(M_B, RIB_B(t)) → F_t → 応答・作用
                                              ↓
                                      相互作用条件が変化
                                              ↓
                                  {RIB_i(t+Δ)}
                                              ↓ B
                                      RIB_B(t+Δ)
```

この循環を認めても、最低動作上は各時点で `{RIB_i} → RIB_B` の断面化を行うことで、解釈・比較・更新の式を有限に維持できる。

### 1.3 通常運転と高負荷再編の二重構造

RDLの最低動作は、以下の2つの状態遷移を包括する。

1. **通常運転（巡航代謝）**: 既存の自己側有限関係拘束構造 `M_B` を用いて `RIB_B` を軽量に解釈・予測・局所比較する（$H < \theta$）。
2. **再編相 $M_\Delta$（高負荷代謝）**: 既存構造では保持・吸収できない不整合が限界に達したとき（$H \ge \theta$）、既存 `M_B` そのものをSILNとして対象化・解剖し、未知から次の `M_B'` を再構成する（形成経路の詳細はT1が規定）。

本仕様は次の二層で構成する。

| 層 | 役割 | 置換可能性 |
|---|---|---|
| **Core Requirement** | RDLとして最低限必要な抽象機能 | 満たすべき機能を変更しない |
| **Standard Model** | Core Requirementを実現する標準的な式・状態・局所モデル | 同等以上の機能を満たすモデルへ置換できる |

## 2. 中核変数

| 記号 | 名称 | 最低限の意味 |
|---|---|---|
| `SILN` | 基底構造 | **Survival-biased Integration of Local Linear Approximations in a Nonlinear Network**。非線形関係ネットワーク内で、局所線形近似が生存偏向的に残存・統合された、RDLが扱う有限構造の基本形 |
| `B` | 有限境界 | 観測・認識・記述・操作のための有限な選択枠組み |
| `ξ` | 未回収関係 | 有限境界に伴って残る関係（非ランダム・未回収の全体） |
| `M_B` | 自己側有限関係拘束構造 | あるSILNを `B` のもとで自己側・解釈側として保持し、現在の解釈・予測・選択・応答・更新を拘束する有限構造 |
| `RIB` | 関係的相互作用束 | **Relational Interaction Bundle**。非線形関係ネットワーク上で成立する相互作用の束。複数のRIBが同時に一つのSILNへ関与し、その構造保持・変化へ寄与しうる |
| `RIB_B` | 有限作用断面 | 一つ以上のRIBを、用途・問いに応じた `B`・観測位置・時間断面・対象方向などから選択・切り出して構成した未解釈の有限作用断面。通常運転で `M_B` が直接解釈する単位 |
| `F` | 作用解釈・予測 | `RIB_B` が `M_B` を通して解釈され、現在構造から形成された作用情報・予測 |
| `F'` | 後続作用解釈 | 後続する `RIB_B'` を、**更新前の同一の `M_B`** が解釈して形成した次の作用情報。元となる後続RIB群は先行相互作用の影響を含んでよい |
| `E` | 不整合 | `F` が含む予測と、後続して形成された `F'` との差異 |
| `H` | 熱・不整合蓄積 | `E` のうち、現在構造で吸収・解消されず、残存・蓄積・伝播した状態 |
| `θ` | 判定境界 | 既存の `M_B` が未解消不整合 `H` を内部で保持・吸収し続けられる限界 |
| `M_Δ` | 再編相 | `H ≥ θ` により既存 `M_B` そのものをSILNとして検査対象化し、未知探索・再編を行う高負荷状態 |
| `C_rel`（任意補助） | 関係拘束強度 | 関係または関係束が特定断面で可能域をどの程度拘束するかを表す性質（Core必須ではなく任意補助概念） |

`M_B` と `RIB_B` はともに `B` 依存の有限断面であり、BASEの `[B-ξ]` に従って特記がなくても $\xi$ を伴う。`M_B` は構造側、`RIB_B` は相互作用側の断面である。個々のRIBは有限作用断面そのものではなく、RDLの通常操作では複数RIBから `RIB_B` を構成して用いる。

## 3. Core Requirement

RDLの最低動作は、以下の機能を満たさなければならない。

| ID | 必須機能 |
|---|---|
| **C1** | SILNをRDLが扱う基底構造として置き、対象または自己側の有限構造として操作できる。 |
| **C2** | 有限境界 `B` を設定できる。 |
| **C3** | `M_B` および `RIB_B` などの `B` 依存断面に `ξ` 残存を付与・継承できる。 |
| **C4** | 関係ネットワーク上で一つ以上の `RIB` がSILNへ関与することを許容し、用途・問いに応じた `B`・観測位置・時間断面・対象方向から有限作用断面 `RIB_B` を構成して扱える。 |
| **C5** | `RIB_B` を `M_B` が `F` として解釈し、予測を形成できる。 |
| **C6** | 現在構造から形成された予測 `F` と、後続する `RIB_B'` から形成された `F'` との差異を不整合 `E` として扱える。元となる `RIB'` は先行相互作用から独立である必要はない。 |
| **C7** | `E` のうち吸収・解消されない残存・蓄積・伝播を熱 `H` として扱える。 |
| **C8** | `H` その他の状態から、維持・局所更新と再編（$M_\Delta$）を分ける判定境界 `θ` を設定できる。 |
| **C9** | 判定結果に応じ、`H < θ` のときは `M_B` を維持・局所更新し、`H ≥ θ` のときは再編相 `M_Δ` へ移行し、再構成された `M_B'` へ復帰できる。更新後の `M_B'` も `B` 依存であり、`ξ` を継承する。 |
| **C10** | RDL自身を通常のSILNとして操作対象にできる（自己例外化禁止）。 |
| **C11** | 各 `RIB` を単純な独立外生入力へ固定せず、RIB同士の重なりやSILNの応答を含め、必要な場合にはその成立条件を相互作用由来の構造として再対象化できる。 |

## 4. 最低動作フロー

自己側の基本動作は、その時点でSILNへ関与する複数のRIBから、用途・問いに応じて構成された `RIB_B` を入力単位とし、通常運転の比較ループと、閾値超過時の再編相 $M_\Delta$ への分岐として記述する。

### 4.1 操作断面

```text
【SILN群 / 相互作用系】
        ↓
 {RIB_1, RIB_2, ...}
        ↓ 用途・問いに応じた B・観測位置・時間断面・対象方向
     RIB_B
        ↓ M_B による解釈・予測
        F
```

ここで個々のRIBの生成過程やRIB群全体を毎回展開する必要はない。ただし `M_B` の応答・作用が相互作用系へ戻り、後続RIB群の成立条件を変化させることを妨げない。

### 4.2 通常運転と再編

```text
【通常運転（H < θ：既知の巡航）】
{RIB_i}
 ↓ 用途・問いに応じた Bによる有限切断
RIB_B
 ↓ M_B による解釈・予測
F
 │
 │ 後続する相互作用条件
 ↓
{RIB_i'}
 ↓ 同一用途・問いのB系による有限切断
RIB_B'
 ↓ 同一の更新前 M_B による解釈
F'
 ↓ Fとの予測差異
E (不整合)
 ↓ 吸収・解消されない差異の残存・蓄積・伝播
H (熱)
 ↓ θによる判定
 ├─ [ H < θ ] ──→ 維持・局所更新（通常運転継続）
 │
 └─ [ H ≥ θ ] ──→ 【再編相 M_Δ（未知高負荷代謝）】
                    ↓ 既存 M_B をSILNとして対象化・解剖
                    ↓ 未知探索・Probe・検査・Selection（T1操作）
                    ↓ 残存関係の抽出・再構成
                   M_B' （新構造として通常運転へ復帰）
```

圧縮表記は次のとおりである。

```text
{RIB_i}  → RIB_B  → F
                  \
                   Δ(F,F') → E → H → θ ──[ H < θ ]──→ Update_local(M_B)
                  /                          │
{RIB_i'} → RIB_B' → F'                           └──[ H ≥ θ ]──→ M_Δ ──→ M_B'
```

* 通常運転において `F'` の形成には、更新後の `M_B'` ではなく、更新前の同一の `M_B` を用いる（安価な反実仮想的比較器としての動作）。
* `RIB_B'` の元となる後続RIB群は単なる独立した次入力ではなく、先行する `M_B` の応答を含む相互作用の結果として変化していてよい。
* `H ≥ θ` に達したとき、系は $M_\Delta$ へ移行し、T1の高負荷代謝（未知探索・選別・再構成）を起動する。

## 5. 抽象更新則

具体的な時間形式やアルゴリズムは固定しない。最低限、更新は次の抽象形式で表現できなければならない。

```text
M_B' = Update(M_B, F, E, H, θ, ξ)
```

差分形式：

```text
ΔM_B = U(M_B, F, E, H, θ, ξ)
```

この更新則は、あるSILNを自己側 `M_B` として扱った最低動作断面を表すものであり、SILN群または相互作用場全体の状態更新を完全記述する式ではない。

連続時間、離散時間、確率的更新、イベント駆動、状態遷移、ニューラル更新などは、C1〜C11を満たす限り排除しない。

## 6. Standard Model

以下は必須定義ではなく、RDLで使用する標準的な具体化である。

### 6.1 RIB群の断面化・解釈・不整合

```text
RIB_B(t)     = Section_B({RIB_i(t)})
F(t)         = interp(M_B, RIB_B(t))

RIB_B(t+Δ)   = Section_B({RIB_i(t+Δ)})
F'(t+Δ)      = interp(M_B, RIB_B(t+Δ))

E(t+Δ)       = Δ(F, F')
```

この式は、相互作用全体を一方向因果へ還元するものではない。各時点で関与するRIB群から、用途・問いに応じた `B` により特定の `M_B` に対して有効な有限作用断面 `RIB_B` を形成し、それを比較するための局所モデルである。

#### RIB群の成立条件の任意展開

必要な場合に限り、後続RIB群の成立条件を概念的に次のように展開できる。

```text
{RIB_i(t+Δ)}
  = InteractionBundles(
      prior_state,
      environment,
      SILNs,
      other_structures,
      response(M_B, F(t)),
      ξ,
      ...
    )

RIB_B(t+Δ)
  = Section_B(
      {RIB_i(t+Δ)},
      purpose_or_question,
      observer_position,
      time_slice,
      target_direction,
      resolution = ρ_B,
      ...
    )
```

`ρ_B` は、現在の有限境界 $B$ の内部で関係差をどこまで細かく区別して操作するかを表す Standard Model 上の操作解像度であり、必要な場合にのみ明示する。

`InteractionBundles` の内部構造を固定することは Core Requirement ではない。対象ごとに異なる相互作用モデルを採用でき、通常運転では個々のRIBの内部生成条件とRIB群全体を畳んだまま `RIB_B` だけを操作してよい。

複数の解釈系が相互作用する場合、それぞれの `interp` の出力に基づく応答が、後続RIB群の成立条件へ入りうる。

```text
RIB_B_{→A} = Section_{B_A}({RIB_i}_{→A})
RIB_B_{→B} = Section_{B_B}({RIB_i}_{→B})

F_A = interp(M_A, RIB_B_{→A})
F_B = interp(M_B, RIB_B_{→B})

response_A → condition({RIB_i'}_{→B})
response_B → condition({RIB_i'}_{→A})
```

ここで重要なのは `interp_A` と `interp_B` が同じ解釈を持つことではなく、**それぞれの解釈に基づく応答が相互作用条件へ戻り、後続するRIB群と、その有限断面 `RIB_B` の成立条件へ接続される**ことである。解釈や予測の不一致が大きい場合、その戻り作用は不整合 `E` の主要な発生源になりうる。

### 6.2 蓄積と更新（整合慣性の断面化）

従来「整合慣性」と呼ばれていた性質は、関係拘束強度の時間・更新抵抗断面 $I(M_B)$ として扱う。

```text
I(M_B) ↑ → 既存の解釈・更新経路への拘束が強い → 局所入力による変形率 κ ↓
```

```text
H = ||H_vec||

H_vec := E のうち、現在の M_B によって吸収・解消されず残存している不整合状態
（局所変形全体を δM_B(t) と置く場合、未解消成分 H_vec = P_unresolved(δM_B(t))）

dM_B/dt = f(M_B, E, ξ)
```

#### 熱 H の残存と時間幅による蓄積（概念補足）

$E$ のうち現在構造で吸収・解消された部分は局所更新として解消され、$H$ には残らない（揺らぎ $\neq 0$ であっても $H \approx 0$ は可能）。未吸収分のみが $H$ として残存する。

```text
H_{n+1} = Remain(H_n, Δt) + Residual(E_{n+1}, M_B, B, ...)
```

* 小さい不整合 $E$ でも、解消時間不足の短時間反復があれば残存 $H$ が加算されて $\theta$ を超えうる。
* 十分に大きい不整合 $E$ であれば、単発の入力で直ちに $H \ge \theta$ となり再編相へ至る。
* 相互作用系では、ある応答が後続RIB群を変え、その結果として切り出される `RIB_B` が類似の不整合を反復生成または減衰させる場合がある。したがって、$H$ の蓄積は外部入力列だけでなく相互作用ループの性質にも依存しうる。

取得される `RIB_B` の操作解像度 `ρ_B` が異なれば、形成される `F / F'`、検出される不整合 `E`、およびその未解消成分として残存する `H` が異なりうる。高い `ρ_B` が常に `E` または `H` を増加させるとは限らない。

#### 実効拘束 C_eff（任意補助概念）

未吸収不整合の蓄積 $H$ は、既存拘束構造の実効的な保持余力を揺らしうる。概念的には、現在状態における実効拘束を以下のように表現できる。

```text
C_eff = f(C_rel, H, B, ...)
```

※ ただし、防衛的固定化なども許容するため、$H \uparrow \to C_{rel} \downarrow$ を普遍的な単調則として固定しない。

### 6.3 判定と相状態

```text
H < θ  → 維持・局所更新（M_act または M_lat）
H ≥ θ  → 再編相 M_Δ への移行
```

相状態の遷移列：

```text
M_B → [ H ≥ θ ] → M_Δ → [ Selection & Reconstruction ] → M_B'
```

* `M_\Delta` 内部では、既存の `M_B` そのものがSILNとして検査対象化され、T1の代謝処理によって新たな `M_B'` が析出・再構成される。

### 6.4 任意の補助モデル

```text
θ_eff(t) = θ + g(ξ(t))
||M_B|| · D[ξ] = 𝒦
```

#### 操作解像度 `ρ`

Standard Modelでは、有限境界 $B$ の内部で関係差をどこまで細かく区別して観測・記述・比較・操作するかを、操作解像度 `ρ_B` として表してよい。

連続モデル等を扱う場合、必要に応じて `ρ → ∞` を**解像度増加に終端を置かない無限解像度措定**として用いてよい。ただし、

```text
ρ → ∞ ≠ Δ = 0
ρ → ∞ ≠ ξ → 0
```

とする。詳細な定義、`B / Δ / ξ` との区別、時間・空間・連続との接続は、TD の `ρ` 詳細文書に委ねる。

## 7. 標準モデルの差替規約

標準モデルを差し替える場合は、少なくとも次の対応を明示する。

| 確認項目 | 明示する内容 |
|---|---|
| `SILN` | 何をRDLが扱う有限構造単位として置くか。非線形関係ネットワーク内の局所線形近似の残存・統合として、どの範囲を対象化するか |
| `RIB` | どの相互作用束をRIBとして識別するか。複数RIBの重なり・媒介・相互依存をどう扱うか。独立外生入力を仮定する場合は、その仮定範囲を明示する |
| `RIB_B` | 一つ以上のRIBから、どの用途・問い・`B`・観測位置・時間・対象方向に基づいて有限作用断面を構成するか |
| `M_B` | どのSILNを、どの `B` のもとで自己側・解釈側の有限関係拘束構造として保持するか |
| `E` | `F` による何の予測と、どの後続 `F'` との何を不整合として検出するか |
| `H` | 何を蓄積・残存状態として扱うか |
| `θ` | 何を維持と再編（$M_\Delta$ 移行）の判定境界とするか |
| `M_Δ` | 高負荷再編相への移行条件、T1代謝への受渡条件、および `M_B'` への復帰条件をどう保持するか |
| 更新 | どの条件で `M_B'` へ遷移・復帰するか |
| `ξ` | 有限境界に伴う未回収関係を、`M_B` と `RIB_B` の双方でどう保持するか |

## 8. T0 / T1 / T2 / 各系設計の責務分担

| 層 | 責務 |
|---|---|
| **T0** | SILNの基底位置、非線形関係ネットワークと相互作用、`{RIB_i} → RIB_B` の断面化、最低動作、維持／再編（$M_\Delta$）の起動判定を保持する。 |
| **T1** | SILNの展開・検査・Selection・再構成、および $M_\Delta$ における高負荷代謝の抽象手順を規定する。必要に応じてRIB群の成立条件自体をSILNとして対象化・展開する。 |
| **T2** | Selection 等に利用可能な汎用検査・評価機構（道具：耐久検査など）を提供する。 |
| **各系設計** | RIB群の具体的相互作用モデル、Probe の身体／センサ／API 実装、`RIB_B` の具体的切り出し方法、Selection の具体基準・許容損失を設計する。 |

## 9. 改訂履歴

- **v2.4（操作解像度ρのStandard Model導入）**：
  - Standard Model に操作解像度 `ρ_B` を追加。
  - `Section_B` の任意切り出し条件として `resolution = ρ_B` を明示。
  - `ρ_B` の違いにより `RIB_B → F/F' → E → H` の有限記述が変化しうることを明記。
  - `ρ → ∞` を無限解像度措定として採用し、`ρ → ∞ ≠ Δ = 0`、`ρ → ∞ ≠ ξ → 0` を仕様上のガードとして追加。
  - 詳細な意味論は TD 共有語彙側へ委託し、Core Requirement および最低動作フローは変更しない。

- **v2.3（RIB導入・複数相互作用束とRIB_B断面化）**：
  - `EFP` / `B_EFP` を廃止し、**RIB = Relational Interaction Bundle** / `RIB_B` へ置換。
  - 一つのSILNに複数のRIBが同時に関与し、その相互作用の中で構造が動的に保持・変化することを明示。
  - `RIB_B = Section_B({RIB_i})` を標準形とし、用途・問いに応じた有限断面として再定義。
  - `M_B` と `RIB_B` を、同じ `B` が構造側／相互作用側に作る対応断面として整理。
  - RIB同士の重なり・媒介・相互依存、およびSILNの応答が後続RIB群へ回り込むことをCore Requirementへ反映。
  - 重力・大気圧・接触・光・音・情報などをRIBの例として明示し、問いに応じて異なるRIB_Bが成立する運用を追加。

- **v2.2（SILN基底化・EFP/B_EFP分離）**：
  - SILNをRDLが扱う基底構造として明示。
  - SILNを **Survival-biased Integration of Local Linear Approximations in a Nonlinear Network** として定義。
  - `M_B` を、SILNを自己側・解釈側として有限に保持する関係拘束構造へ再配置。
  - `EFP` を、有限作用断面ではなく場側の相互作用束へ再定義。
  - `B_EFP = Section_B(EFP)` を導入し、通常運転で直接解釈する有限作用断面を `B_EFP` へ分離。
  - Standard Model の基本式を `F = interp(M_B, B_EFP)` へ変更。
  - 後続相互作用を `EFP' → B_EFP' → F'` とし、応答が後続 `EFP` の成立条件へ回り込む構造を維持。
  - Core Requirementを `C1〜C11` へ再編し、SILN基底・EFP断面化・自己適用を明示。
- **v2.1（相互作用・EFP断面改定案）**：
  - `EFP` を独立外生入力ではなく、相互作用から `M_B` 側へ切り出された未解釈の作用束として再定義。
  - `EFP` の内部生成過程が複雑であり、複数構造・履歴・環境・先行応答を含みうることを明記。
  - `M_B` の応答が相互作用系へ戻り、後続 `EFP'` の生成条件を変化させうることを追加。
  - Core Requirement にEFP生成条件の再対象化可能性を追加。
  - Standard Model の基本式 `F = interp(M_B, EFP)` は維持し、相互作用展開を任意補助モデルとして追加。
  - 複数 `interp` の接続と、不整合 `E` の相互作用的発生を概念補足として追加。
- **v2.0（関係拘束改定案）**：
  - $M_B$ の名称を「有限関係拘束構造」に変更。
  - $E$ の名称を「不整合」へ純化（旧称：慣性誤差）。
  - 整合慣性を関係拘束強度の時間・更新抵抗断面として再位置づけ。
  - $H$ の時間幅残存モデル、実効拘束 $C_{eff}$、$\theta$ の保持限界解釈を Standard Model 概念補足として明文化。
- **v1.2**：標準モデル差替規約の $M_\Delta$ を純化。
- **v1.0**：依存先を「基底措定（BASE）」へ更新。巡航と再編相 $M_\Delta$ の二重構造を明記。
