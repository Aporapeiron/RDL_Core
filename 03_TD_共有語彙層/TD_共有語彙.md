## ■ 1. 基底量と記号一覧

| 記号 | 名称 | 定義・役割 |
| :--- | :--- | :--- |
| **$B$** | 有限境界（Finite Boundary） | 観測・認識・記述・操作を行うための有限な選択枠組み（対象、尺度、語彙、差異、評価関数、用途、観測者等を含みうる）。 |
| **$\xi$** | 未回収関係・揺らぎ（Residual Relation） | 有限な境界 $B$ を引くことに伴い必ず生じる非線形残差・こぼれ落ちた差異。$[B\text{-}\xi]: \forall B_{\text{finite}}, \xi(B) \neq 0$ |
| **$M_B$** | 整合慣性（Consistency Inertia） | 現在の境界 $B$ の内部で保持されている整合構造・自己の身体（操作表現）。固有分解 $M_B = V_B \Lambda_B V_B^{-1}$ |
| **$EFP$** | 素流圧（Elementary Flux Pressure） | 外部から流入する未解釈の作用束。直接観測不能量（逆算推定概念）。 |
| **$F$** | 作用解釈（Flux Interpretation） | $M_B$ が $EFP$ を解釈した結果。観測者が手にする唯一の作用情報（$F = \text{interp}(M_B, EFP)$）。 |
| **$E$** | 慣性誤差（Inertial Error） | 実際に来た次の作用 $F(t+\Delta)$ と慣性投影 $M_B \cdot F(t)$ との差分（$E(t) = F(t+\Delta) - M_B \cdot F(t)$）。 |
| **$H$** | 熱・誤差蓄積（Accumulated Heat） | 慣性誤差 $E$ の時系列積分・未拘束自由度の振動（$H = \|H_{\text{vec}}\|, H_{\text{vec}} \equiv \delta M_B(t)$）。 |
| **$\mathcal{K}$** | 関係保存量（Relational Invariant） | 境界 $B$ における局所不変量（$\|M_B\| \cdot D[\xi] = \mathcal{K}$）。 |
| **$\theta_{\text{eff}}$** | 実効跳躍閾値（Effective Threshold） | 構造が相転移を起こす限界値。$\theta_{\text{eff}}(t) = \theta + g(\xi(t))$ により $\xi$ で揺らぐ。 |

## ■ 2. 中核概念ラベル

| ラベル | 正式名称 | 定義・概念 |
| :--- | :--- | :--- |
| **Aporapeiron** | アポラペイロン | 有限境界 $B$ による閉包が未回収関係 $\xi$ を伴い、終端的閉包として固定されないという**関係的・操作的非閉包条件**（使えても閉じ切ったとはみなさない側）。 |
| **Aporapeiron Stance** | アポラペイロン・スタンス | 有限 $B$ の非閉包性を前提に、$M_B$ を終端化せず、必要に応じて $B$・解釈・操作を更新可能として保持する**T1 運用姿勢・原則規約**（人間・AI共通）。 |
| **SILN** | SILN（対象構造・食材） | *Survival-biased Integration of Local Linear approximations in a Nonlinear Network*。<br>有限境界 $B$ のもとで、ひとまとまりの操作対象（代謝の対象）として切り出された安定関係構造の身分（閉じ切らなくても使える側）。 |
| **SILN展開** | SILN展開（旧称：SILN分解） | 対象の関係・状態・係数・$\xi$ の可能性空間を RDL 内部で操作可能な形へ広げ・開く操作（T1 探索・生成側）。 |
| **検査と選別** | 検査と選別（絞り込み） | 統計・実験・シミュレーション・耐久検査等の多様な手段で候補を評価し、適合構造を局所的に絞り込む操作（T1 評価・選択側）。 |
| **再構成** | 再構成（血肉化・合成） | 選別された残存構造を、新安定相 $M_B'$ として入れ子ネットワークへ定着・血肉化させる操作（T1 定着・合成側）。 |
| **SILN耐久検査** | SILN耐久検査（旧称：構造破壊学） | 負荷を印加して破断条件・有効範囲・残存構造を同定し、構造耐久証明書を発行するストレステスト技法（T2 応用）。 |
| **$[SELF]$** | 自己例外化禁止 | $RDL \in \text{dom}(RDL)$。RDL 自身も例外化せず、通常の SILN 操作・再仮設の対象とする基底規則。 |
| **$[B\text{-}\xi]$** | $B$-$\xi$ 性質 | $\xi$ は後付けのノイズではなく、有限な境界 $B$ を持つことそのものに伴う不可避の性質。 |
| **$\text{Space}_B$** | 局所空間表現 | 空間は基底実体ではなく、関係ネットワークを扱いやすくするための表現形式（道具）の一つ。 |

## ■ 4. 説明用補助表記

| 表記 | 意味・運用ルール |
| :--- | :--- |
| **`ADDξ(x)`** | **説明用補助表記（Syntactic Sugar）**<br>コア演算ではなく、「対象 $x$ にも通常は暗黙になっている $\xi$ が存在することを明示・強調する」ための記法。<br>例：$\text{ADD}\xi(\text{真理}) = \text{真理} + \xi$（真理というラベルを保持しつつ終端閉包を解除する）。 |

## ■ 5. 自然言語・思考概念の置換対応表

RDL 運用において確定化（$\xi=0$ の主張）に陥りやすい日常語・哲学語の置換先：

| 確定化しやすい語 | RDL における置換概念・解釈 |
| :--- | :--- |
| **客観** | **間主観的再現性**（観測者非依存の絶対視点ではなく、「誰が B を引いても ξ から逃げられない」普遍性）。 |
| **中立・公平** | **偏りの自覚と引き直し**（偏りゼロは構造的に不能。どの B で偏っているかを自覚し、固着せず引き直す）。 |
| **真理・絶対** | **$\text{ADD}\xi(\text{真理})$**（禁止せず保持するが、終端閉包されない仮設として扱う）。 |
| **安定** | **$\xi$ が解像度以下に潜っている見え方**（$\xi=0$ ではなく、整合慣性 $M_B$ が揺らぎを吸収している状態）。 |
| **破綻・失敗** | **次の境界 $B$ を導く診断情報**（欠陥ではなく、新たな SILN を生み出すための契機）。 |
