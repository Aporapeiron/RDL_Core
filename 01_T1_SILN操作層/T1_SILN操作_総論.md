## ■ 0. 位置づけ

本文書は、関係力学言語（RDL）における**SILN操作（SILN Operations）の全体体系、代謝モデル、操作可能性のグラデーション、基本代謝サイクル、および運用者の実践的構え（Aporapeiron Stance）**を規定する。

T0（基盤層）が「何が仮設され、最低限どう動くか」を定めたのに対し、T1（SILN操作層）は**「対象をRDL内部でどのように観測・展開・検査・選別・再構成するか（どう処理するか）」**という中核代謝処理を担う。

## ■ 1. SILN操作の定義

```text
SILN操作 :=
SILN または SILN 候補に対して行う
観測・切出・記述・展開・測定・検査・選別・再構成の総称
```

## ■ 2. 生物的代謝モデル（Metabolic Model）

RDL の SILN操作は、生物の**代謝系（Metabolism）**を主要な構造写像（道具）として理解できる。

```text
【生体構造】        【RDL SILN操作】
生存基盤（細胞・DNA）  ──  T0 基盤（Relational Network, B, ξ, M_B）: 生存基盤
代謝系                ──  T1 SILN操作                              : 代謝プロセス
酵素群                ──  個別操作モジュール（展開・測定・検査・選別・再構成）
食材（食物）          ──  SILN（ひとまとまりの操作対象として切り出された安定構造）
摂取・消化            ──  SILN展開（取り込みと可能性空間の展開）
選別・品質検査        ──  検査と選別（統計・実験・T2耐久検査等による絞り込み）
合成・血肉化          ──  再構成（新たな自己の身体 M_B' の定着）
器官・手段            ──  表現形式の選択（空間・グラフ・時間・代数）
```

> **「生きている」の操作的定義：**
> 生きているとは、単に閉じていないことではなく、**「閉じ切らずに代謝し続けられること」** である。
> 完全に閉じた系（$\xi=0$ を主張する確定化）は外部の差異を受け取れず死滅する。
> 有限境界 $B$ が必ず $\xi$ を残す（$[B\text{-}\xi]$）からこそ、新たな差異 $E$ が生まれ、展開 $\to$ 選別 $\to$ 再構成の代謝が回り続ける。
> 
> ※「RDL は生命である」という存在論的主張ではなく、更新・代謝・非終端性を理解するための**構造写像（道具）** として本モデルを採用する。

SILN の射程は原理的にすべてに及ぶが、すべての SILN が同じ仕方で操作できるわけではない。
SILN は二値（「操作可能／操作不能」）ではなく、**境界 $B$ と解像度に応じた連続的なグラデーション**を持つ。

```text
【操作可能性のグラデーション】
高 ： 展開・追従・借用・設計が直接行える領域
      例：個体の習慣、制度、物理工学、ニュートン力学

中 ： 粗い近似なら扱えるが、精密化が難しい領域
      例：生態系全体、文明、集合的無意識、複雑適応系

低 ： 現実文脈では直接操作できず、主に逆算的に仮設される領域
      例：EFP（素流圧）、ξ（未回収関係）、𝒦（関係保存量）
```

## ■ 4. 基本代謝サイクル（Core Cycle）

RDL の SILN操作は、以下の**「展開 $\to$ 検査・選別 $\to$ 再構成」の動的サイクル**を基本骨格とする。

```text
SILN展開（広げる / 探索・生成） ──→ 検査と選別（絞る / 評価・選択） ──→ 再構成（血肉化 / 定着・合成）
     ↑                                                                    │
     └─────────────────────────── ΔB（引き直し） ─────────────────────────┘
```

```text
T1 中核モジュール
├─ ① B設定 / ΔB     : 境界の仮設と引き直し（直感・異常信号の配置）
├─ ② SILN展開       : 関係・状態・係数・ξ の可能性空間を広げる（探索・生成側）
├─ ③ 検査と選別     : 統計・実験・シミュレーション・耐久検査(T2)等で絞る（評価・選択側）
└─ ④ 再構成         : 選別された構造を新たな安定相 M_B' として定着させる（血肉化・合成側）
```

### 4.1 代謝サイクルの適用相（翻訳・学習・理解・自己更新）

日常語や学術で用いられる以下の行為は、独立した特殊機構ではなく、**「基本代謝サイクルを何に対して回したか」** を表す運用相にすぎない。

```text
・翻訳 / 借用  : 基本代謝を「外部理論・異分野構造」に対して回した状態
・学習 / 理解  : 基本代謝を「未知の入力データ・経験」に対して回した状態
・自己更新     : 基本代謝を「観測者自身の既存 M_B（[SELF]）」に対して回した状態
```

## ■ 5. 表現形式の選択（道具としての表現）

得られた $M_B$ をどの形式で表現・モデル化するかは、$B$ と目的に応じた**道具選択**である。

```text
M_B
  ↓ representation selection
  ├─ 空間表現（Space_B）       : 位置・距離・近接・移動を扱う場合
  ├─ グラフ表現               : 離散関係・ネットワークトポロジーを扱う場合
  ├─ 時系列表現               : 状態遷移・履歴・因果プロセスを扱う場合
  ├─ 階層表現                 : 入れ子ネットワーク・支配従属を扱う場合
  ├─ 代数・数式表現           : 定量シミュレーション・保存則計算を行う場合（T2 計算拡張）
  └─ ナラティブ表現           : 人間的意味・物語・意図を扱う場合
```

## ■ 6. 運用姿勢：Aporapeiron Stance（アポラペイロン・スタンス）

SILN操作を実際に行う観測者（人間担体・自律AI担体）が保つべき基本構え・運用規約を **「Aporapeiron Stance（アポラペイロン・スタンス）」** と呼ぶ。

```text
Aporapeiron         : T0 基底条件（有限 B による終端閉包不能性）
       ↕
Aporapeiron Stance  : T1 運用姿勢（その条件を前提とした動的運用規約）
```

### 6.1 6つの運用原則（Operation Principles）

```text
1. 現在の B を自覚する       : 今どの境界・尺度・語彙で切り出しているかを把握する
2. M_B を終端化しない        : 安定した構造を「絶対の真理」として固定しない
3. ξ の残存を欠陥扱いしない  : こぼれ落ちた未回収関係を次の動態の母体として受け止める
4. E / H を更新情報として扱う : 不整合（E）や蓄積（H）を世界や自己への断罪ではなく更新シグナルとする
5. 必要なら ΔB する          : 破断が検知されたら自己側の境界 B を引き直す
6. RDL 自身も例外化しない    : [SELF] 原則に従い、RDL 自身の理論・コードも更新対象とする
```
