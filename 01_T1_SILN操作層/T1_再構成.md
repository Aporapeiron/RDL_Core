## ■ 0. 位置づけ

本文書は、SILN操作における **合成・定着フェーズである「再構成（Reconstruction / Internalization）」** の必須手順、再構成様態、および血肉化の規約を定める。

SILN展開が可能性を広げ、検査と選別が現在の $B$・目的・制約に対して残存可能な関係を絞った後、再構成は **選別・残存した関係を、新たな自己側有限関係拘束構造 $M_B'$ として定着させ、後続する `RIB_B` を解釈・予測できる通常運転へ復帰させる**合成責務を担う。

```text
SILN展開（広げる）
  → 検査と選別（絞る）
  → 再構成（M_B' として定着）
  → RIB_B' の解釈を含む通常運転へ復帰
  → 必要に応じ ΔB / 再展開
```

再構成によって成立する $M_B'$ も SILN の一つの有限な自己側断面であり、終端構造ではない。また $M_B'$ の応答は相互作用系へ戻り、後続する RIB の成立条件を変化させうる。

## ■ 1. 再構成の必須5工程（Core Reconstruction）

```mermaid
graph LR
    C["Step 1: 適合構造受領<br/>(残存核・有効条件)"]
    --> B["Step 2: 境界適合・再措定<br/>(B / B' / ΔB)"]
    --> S["Step 3: M_B' 定着<br/>(新安定相の合成)"]
    --> N["Step 4: 関係網・RIB条件へ再接続"]
    --> I["Step 5: ξ' 継承<br/>(通常運転へ復帰)"]
```

```text
Step 1: 選別構造の受領（Candidate Intake）
        検査と選別から、retain された関係・残存核、
        有効範囲、破断条件、関連 RIB_B 条件、未解決事項を受け取る。

Step 2: 境界の適合・再措定（Boundary Adaptation / Re-postulate）
        選別結果の有効範囲と現在の用途・問いに応じて B を維持・調整・引き直す。
        修復では B' ≈ B、跳躍では B → B' の変更を許容する。

Step 3: 新安定相 M_B' の合成・定着（Synthesis & Stabilization）
        残存関係を核として、新たな自己側有限関係拘束構造 M_B' を形成する。
        M_Δ 内にある場合は、再編相から巡航可能な有限構造へ復帰させる。

Step 4: 関係網・RIB条件への再接続（Relational Reintegration）
        M_B' を上位・下位・隣接する SILN / 有限構造と再接続し、
        どの RIB / RIB_B 条件下で機能するかを運用可能な形で保持する。
        M_B' の応答が後続 RIB の成立条件を変えることも許容する。

Step 5: ξ' の暗黙継承と通常運転への復帰（Re-entry）
        M_B' も有限境界のもとで成立するため ξ' ≠ 0 を伴う。
        後続する RIB_B' を M_B' が解釈する通常運転へ戻す。
```

通常運転への復帰は、標準的には次のように表せる。

```text
RIB_B'(t) = Section_{B'}({RIB_i(t)})
F_new(t)  = interp(M_B', RIB_B'(t))
```

境界を維持する場合は $B' = B$ とみなしてよい。

## ■ 2. 再構成の三様態（Reconstruction Modes）

破断の規模や対象の性質に応じ、再構成は少なくとも次の三様態をとりうる。

```text
【再構成の三様態】
├─ ① 修復・微小更新（Repair Mode）
│     H < θ の通常運転または軽量 T1 内で、
│     既存 M_B の局所パラメータ・接続・重みを修正する。
│
├─ ② 跳躍定着・再結晶化（Phase Shift Mode）
│     H ≥ θ により M_Δ を経て、
│     構造のトポロジーや関係結合を大きく組み替えた M_B' を成立させる。
│
└─ ③ 共存・並立統合（Coexistence / Parallel Mode）
      旧構造を全否定せず、有効な B / RIB 条件の異なる複数モデルを並立保持し、
      条件に応じて使い分ける。
```

たとえばニュートン力学と一般相対論のように、有効境界・作用条件が異なる複数のモデルを共存させる場合、再構成は単純な「旧構造の破棄」ではなく、**適用条件を伴う関係拘束の再配置**となる。

## ■ 3. 血肉化（Internalization）の規約

RDL における「血肉化」は、外部の知識や候補構造を無批判に取り込むことではない。

> **選別された関係を、どの B・RIB 条件で有効かを保持したまま、後続 `RIB_B` を解釈・予測し、応答を生成する自己側有限関係拘束構造 $M_B'$ として組み込むこと**

を意味する。

```text
【血肉化の四原則】
1. 有効範囲の保持
   どの B、用途・問い、RIB / RIB_B 条件で残存した構造かを可能な範囲で保持する。

2. 作用解釈器の更新
   選別された関係核を M_B' へ組み込み、
   F_new = interp(M_B', RIB_B') を成立させる。

3. 相互作用への再接続
   M_B' は受動的な解釈器だけではなく、応答を返し、後続 RIB の成立条件へ影響しうる。

4. ξ' の暗黙継承
   新構造も有限であり、ξ' ≠ 0 を伴う。再構成結果を終端真理として固定しない。
```

## ■ 4. 再構成後の検証

再構成は $M_B'$ を作った時点で完了とは限らない。新構造が通常運転へ復帰できるかを、後続 `RIB_B'` に対する解釈・応答で確認する。

```text
M_B'
  ↓ RIB_B'
F_new
  ↓ 後続断面との比較
E_new → H_new
```

- $H_new < \theta$ に収まり、目的に対する機能が維持されるなら巡航へ復帰する。
- 直ちに大きな不整合が再発する場合は、再構成候補・Selection 基準・$B$・Probe のいずれかを再対象化し、T1 サイクルへ戻す。

この再検証も有限であり、完全保証ではない。

## ■ 5. 一文圧縮

> **再構成とは、検査・選別で残存した関係を、その有効な境界・相互作用条件とともに新たな自己側有限関係拘束構造 $M_B'$ として定着させ、`RIB_B' → interp(M_B', RIB_B')` の通常運転へ復帰させる T1 の合成操作である。**
