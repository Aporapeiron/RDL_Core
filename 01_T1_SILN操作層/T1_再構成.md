## ■ 0. 位置づけ

本文書は、SILN操作における**合成・定着フェーズである「再構成（Reconstruction / Internalization）」の必須手順、再構成様態、および血肉化の規約**を定める。

SILN展開が可能性を「広げ」、検査と選別が「絞った」後、再構成は**「選別された残存構造を、次の入力（EFP）を解釈・予測する新たな作用解釈器 $M_B'$（＋$\xi'$）として自己のシステム内へ定着・血肉化させる」**極めて重要な合成責務を担う。

```text
SILN展開（広げる / 探索・生成） ──→ 検査と選別（絞る / 評価・選択） ──→ 再構成（血肉化 / 次の M_B' 定着）
     ↑                                                                    │
     └─────────────────────────── ΔB（引き直し） ─────────────────────────┘
```

## ■ 1. 再構成の必須5工程（Core Reconstruction）

```mermaid
graph LR
    C["Step 1: 適合構造受領<br/>(選別結果 / 耐久証明書)"] 
    --> B["Step 2: 境界再仮設<br/>(ΔB の設定)"] 
    --> S["Step 3: M_B' 定着<br/>(新安定相の合成)"] 
    --> N["Step 4: 網連成<br/>(入れ子ネットワーク接続)"] 
    --> I["Step 5: ξ' 継承<br/>(次サイクル待機)"]
```

```text
Step 1: 選別構造（または構造耐久証明書）の受領（Candidate Intake）
        検査と選別（または T2 SILN耐久検査）から出力された適合構造・残存核・有効境界情報を受け取る。

Step 2: 境界の適合・再仮設（Boundary Adaptation / Re-hypothesis）
        選別構造の有効範囲や目的に応じて、境界 B を適合・再仮設する。
        （※ 修復モードでは B' ≈ B として境界を維持し、跳躍モードでは B → B' と引き直す）

Step 3: 新安定相 M_B' の合成・定着（Synthesis & Stabilization）
        残存構造を核として、新たな整合慣性 M_B' を形成・定着させる。
        （M_Δ 再編相から M_B' 安定相への移行）

Step 4: 入れ子ネットワークへの接続・連成（Network Integration）
        新 M_B' を上位・下位・隣接する他の M_B と結合係数 W_ij で連成させる。

Step 5: 新たな ξ' の暗黙継承（Implicit ξ' Inheritance）
        新 M_B' も有限境界 B' のもとにあるため、暗黙に ξ' を継承し、次なる更新サイクルへ備える。
```

## ■ 2. 再構成の三様態（Reconstruction Modes）

破断の規模や対象の性質に応じて、再構成は以下の三様態をとる。

```text
【再構成の三様態】
├─ ① 修復・微小更新（Repair Mode）
│     整合相内（H < θ_eff）での微小なパラメータ修正。局所破断の吸収。
│
├─ ② 跳躍定着（Phase Shift Mode）
│     跳躍相（M_Δ）を経て、構造のトポロジーや関係結合そのものを組み替えた新安定相 M_B' の樹立。
│
└─ ③ 共存・並立統合（Coexistence / Parallel Mode）
      旧構造を全否定・破棄せず、有効範囲の異なる複数の M_B を階層的に並立保持する。
      （例：低速・弱重力用の NAM と、高速・強重力用の GR を使い分ける運用）
```

## ■ 3. 血肉化（Internalization）の規約

RDL における「血肉化」とは、単に知識や構造を無批判に取り込むことではない。
**「選別された構造を、次の入力（EFP）を受け取って解釈（F）し、予期を立てるための自己の新たな整合慣性 $M_B'$ として能動的に組み込むこと」** である。

```text
【血肉化の三原則】
1. 有効範囲の自覚   : その構造がどこで機能し、どこで壊れるか（証明書・検査結果）を把握した上で使う。
2. 作用解釈器の更新 : 選別された関係核を自己の慣性 M_B' へ組み込み、次の F = interp(M_B', EFP) を駆動する。
3. ξ' の暗黙継承    : 血肉化した新構造も有限 B' の産物であり、新たな ξ' を伴っていることを忘れない（非終端性）。
```

## ■ 4. 一文圧縮

> 再構成とは、検査・選別された残存構造に基づき、有効境界 $B'$ を引き直して新たな安定相 $M_B'$（＋$\xi'$）として入れ子ネットワークへ定着・血肉化させる合成操作である。
