## ■ 0. 位置づけ

本文書は、SILN操作における探索・生成フェーズである **「SILN展開（SILN Expansion / Unfolding）」** の目的、必須手順、展開手段、および通常展開と未知高負荷展開の仕様を定める。

SILN は RDL の基底構造であり、「有限境界 $B$ によって初めて作られる対象側の食材」ではない。T1 における SILN展開とは、**ある SILN を用途・問いに応じて対象化し、有限に取得できる `RIB_B`、既存の解釈・モデル、履歴等から、その関係構造・状態・係数・破断候補の可能性空間を操作可能な形へ広げる操作**である。

従来の「分解（Decomposition）」という呼称は要素還元に偏りやすいため、引き続き「展開（Expansion / Unfolding）」を用いる。

```text
SILN展開（広げる / 探索・生成）
  → 検査と選別（絞る / 評価・選択）
  → 再構成（定着・合成）
  → 必要に応じ ΔB / 再展開
```

---

## ■ 1. SILN展開の定義

```text
SILN展開 :=
対象化された SILN について、
現在の B のもとで取得された RIB_B 列、F/E/H、既知理論・履歴等を手掛かりに、
内部関係、結合パターン、対象側局所モデル M_{B,target}、
候補構造群、破断候補、および ξ の可能性を
RDL 内部で操作可能な形へ広げ・開く操作
```

### 1.1 身分区別

- **SILN**：RDL の基底構造。自己／対象のどちらかに本質的に限定されない。
- **$M_B$**：ある SILN を現在の $B$ のもとで自己側・解釈側として保持した有限関係拘束構造。
- **`RIB_B`**：一つ以上の RIB を現在の用途・問いに応じて有限に切り出した未解釈作用断面。
- **$M_{B,target}$**：対象化した SILN について T1 内部で推定・展開する対象側局所モデルの補助表記。Core Primitive ではない。
- **$\{M_B^i\}$**：候補構造群を表す補助表記。自己側 $M_B$ そのものとは区別する。

### 1.2 通常展開と高負荷展開

- **通常時**：既知の対象、既存理論、観測された `RIB_B`、履歴から関係・パラメータ・候補モデルの可能性空間を広げる。
- **高負荷再編時（$M_\Delta$）**：Probe により条件を変え、その結果として得られた `RIB_B^{probe,k}` 列と解釈差分から、既存 $M_B$ では吸収できなかった関係を再展開し、候補構造群を広げる。

## ■ 2. B 設定の起点（B Setting Triggers）

境界 $B$ を設定・再設定し、展開を開始する契機は担体に応じて多様である。

```text
【B 設定の起点候補】
├─ 直感・違和感   : 「何かがズレている」「ここを分けて見たい」という感覚
├─ 異常信号・偏差 : E の増加、予測偏差、評価関数の乖離
├─ 破断の検知     : H ≥ θ による M_Δ への移行
├─ 外部要求       : 課題、観測目的、インターフェースの変更
├─ RIB_B の変化   : 作用断面の構成・強度・方向・時間パターンの変化
└─ 探索的試行     : 新たな関係を探るための Probe・実験的切り出し
```

$B$ は対象だけでなく、尺度、解像度、時間幅、観測位置、語彙、差異、評価関数、用途・問いを含みうる。同じ SILN / RIB 群でも、$B$ が変われば異なる $M_{B,target}$ や `RIB_B` が成立しうる。

## ■ 3. 必須手順（Core Procedure）

SILN展開において最低限必要な機能手順は以下の5段階とする。

```text
Step 1: 境界 B の設定
        対象化する SILN、用途・問い、尺度、解像度、時間幅、語彙、差異、評価関数、観測者を設定する。

Step 2: RIB_B・履歴・既知構造の取得
        現在の B で取得可能な RIB_B、F/E/H、既知理論、履歴を集める。
        M_Δ では Probe により相互作用条件を変え、RIB_B^{probe,k} の列を得る。

Step 3: 対象側関係構造の推定・展開
        RIB_B 列や既知関係から、対象化した SILN の内部関係・結合・状態遷移を推定し、
        M_{B,target} または候補構造群として複数仮説を開く。

Step 4: 状態量・係数・破断候補の抽出
        目的に応じて、拘束強度、揺らぎ、保存量、保持限界、脆弱性、波及経路等を抽出・推定する。

Step 5: ξ の残存保持と未説明差分の追跡
        有限 B で回収されない関係 ξ ≠ 0 を保持し、
        モデル化できない RIB_B の変化、解釈差分、不整合 E、熱 H の残存・波及を追跡する。
```

Probe の標準接続は次のように書ける。

```text
Probe_B(target, condition_k)
  → RIB_B^{probe,k}

F_k = interp(M_B, RIB_B^{probe,k})

{Δ}_B = Compare({RIB_B^{probe,k}}, {F_k}, prior)
```

`{Δ}_B` は有限差分の一般表記であり、世界や RIB 全体を直接取得したものではない。

## ■ 4. 展開手段の選択と「酵素の借用」

SILN展開の手法は固定しない。目的に応じて適切な展開器を選択し、外部理論・方法を **「酵素の借用」** として利用できる。

```text
対象化された SILN
+ RIB_B 列 / F / E / H / 履歴 / 既知理論
  ↓ finite B
【展開手段の選択】
  ├─ Method A : RDL 標準定量的プロファイル
  ├─ Method B : 統計解析・時系列解析・多変量解析
  ├─ Method C : グラフ・ネットワーク解析・トポロジー
  ├─ Method D : 力学系・制御理論・状態空間モデル
  ├─ Method E : 心理学・認知科学モデル
  ├─ Method F : 既存科学理論・ドメイン専門知識
  └─ Method G : LLM / 基盤モデルによる意味構造・ナラティブ抽出
  ↓
【翻訳・借用】
  ↓
M_{B,target} / 候補構造群 {M_B^i}（with ξ ≠ 0）
  ↓
【検査と選別へ受け渡し】
```

外部理論が対象をすでに洗練された形で記述している場合、RDL側で再発明する必要はない。ただし、その理論も有限境界・適用範囲を持つ SILN として扱い、無条件の終端真理にはしない。

## ■ 5. 標準定量的プロファイル（Standard Quantitative Profile）

以下は Core 必須ではなく、連続数理・物理・計算実装等で利用できる標準的な具体化の例である。

### 5.1 有限関係モデルの固有分解

自己側 $M_B$ または対象側補助モデル $M_{B,target}$ を、適切な表現が成立する場合に安定方向と強度へ展開できる。

```text
M_B = V_B Λ_B V_B⁻¹
```

対象側では同様に、

```text
M_{B,target} = V_{B,target} Λ_{B,target} V_{B,target}⁻¹
```

等の表現を採用してよい。

### 5.2 標準係数群（Standard Model 例）

- **整合慣性断面 $I(M_B)$**：自己側構造の時間・更新抵抗断面。
- **揺らぎ拡散度 $D[\xi]$**：未回収関係の拡散度・ノイズ分散を近似する補助量。
- **局所関係保存量 $\mathcal{K}$**：局所的・近似的に不変として扱う関係量。
- **実効保持限界 $\theta_{eff}$**：$\theta$ に局所条件・$\xi$ 等の影響を含めた補助モデル。

これらは Core Primitive ではなく、対象・表現形式に応じて差し替え可能である。

## ■ 6. 入れ子構造と破断候補・波及経路の展開

SILN は単一階層に限定されず、現在の $B$ のもとで複数の有限関係モデルが入れ子・並列・隣接して表現されうる。

```text
M_{B,target}(parent)
  ├─ M_{B,target,1}
  │   ├─ M_{B,target,1-a}
  │   └─ M_{B,target,1-b}
  ├─ M_{B,target,2}
  └─ M_{B,target,3}
```

展開では安定構造だけでなく、次の可能性も開く。

- **局所破断経路**：下位局所構造の変化にとどまり、上位拘束が維持されうる経路。
- **広域破断経路**：上位構造の破綻が下位全体へ波及する経路。
- **連鎖破断経路**：局所不整合・熱・RIB_B の変化が複数階層へ伝播し、広域再編へ至る経路。

自己側 $M_B$ を対象化して展開する場合にも同じ考え方を適用できる。

## ■ 7. 展開実演（Examples：検査・選別への受け渡し）

以下は「真の構造」を確定する例ではなく、特定の $B$ において候補構造と破断条件を開く例である。

### 7.1 物理担体：鉄の核的安定性と極限環境候補

- **境界 $B$**：原子核スケール、結合エネルギー評価。
- **関与する RIB_B の例**：核力・電磁相互作用・熱／圧力条件の有限断面。
- **展開された $M_{B,target}$**：核子あたり結合エネルギーが高い安定パターン。
- **破断候補**：高温高密度・極限重力条件等における構造変化。
- **検査へ渡す仮説**：どの条件変化で現在モデルの安定域が破れるか。

### 7.2 社会担体：国家・制度

- **境界 $B$**：社会スケール、正統性・法規範・資源配分評価。
- **関与する RIB_B の例**：制度的要求、情報流、経済的圧力、参加者の応答。
- **展開された $M_{B,target}$**：法・貨幣・儀礼・信認等の拘束関係モデル。
- **破断候補**：内部矛盾、信認低下、資源偏在、外的危機。
- **検査へ渡す仮説**：どの負荷条件で現在の拘束配置が維持不能になるか。

### 7.3 記述担体：ニュートン力学と代替仮説

- **境界 $B$**：低速・弱重力領域。
- **関与する RIB_B の例**：観測運動・力・時間計測の有限断面。
- **展開された $M_{B,target}$**：古典運動方程式による関係モデル。
- **破断候補**：光速近傍・強重力領域等。
- **検査へ渡す仮説**：適用範囲を越えた条件で、別の関係モデルがより頑健に残るか。

## ■ 8. 一文圧縮

> **SILN展開とは、SILN を用途・問いに応じて対象化し、有限に取得された `RIB_B` 列、現在の解釈・履歴・既知理論等を手掛かりに、対象側関係モデル・候補構造・破断条件・未説明差分の可能性空間を広げ、検査と選別へ渡す T1 の探索・生成操作である。**

## ■ 9. 改訂メモ

- **v1.1（SILN基底化・RIB同期）**
  - SILN を対象側だけの構造から基底構造へ同期。
  - EFP 系記述を廃止し、RIB / `RIB_B` を展開入力へ導入。
  - Probe を `RIB_B^{probe,k}` の取得・比較へ接続。
  - 対象側モデルを $M_{B,target}$ として補助表記に整理し、自己側 $M_B$ との身分差を明記。
