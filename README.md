# RDL Core

**RDL (Relational Dynamics Language / 関係力学言語)** の基盤仮設・最低動作仕様・基本代謝プロセス・共有語彙・解説・基本操作例を保持するコアリポジトリ。

RDL は、対象を関係として記述し、有限境界のもとで切り出した構造を、閉じ切った真理ではなく操作可能な仮設として扱うための記述・操作フレームワークである。

> **閉じ切らない。しかし、扱える。**

## T0 — 基盤層

RDL が採用している基底仮設と、RDL として最低限必要な動作仕様を定義する。

### 基底仮設（HYP）

- 関係記述
- 有限境界 `B`
- 非終端閉包性
- `[B-ξ]`
- `[SELF]`

### 最低動作仕様（SPEC）

- `B`
- `ξ`
- `M_B`
- `EFP`
- `F`
- `E`
- `H`
- `θ`
- `Update(M_B)`

T0 は「なぜそう考えるのか」よりも、**現在の RDL が何を前提とし、最低限どう動くか**を保持する。

---

## T1 — SILN操作層 / 代謝プロセス

有限境界 `B` のもとで操作対象として切り出された構造を **SILN** として扱い、次の基本代謝を行う。

```text
SILN
  ↓
SILN展開
  ↓
検査と選別
  ↓
再構成
  ↓
M_B'
```

直感的には、

```text
SILN = 食材
M_B  = 現在の身体
M_B' = 代謝後の身体
```

という関係にある。

同じ構造でも、

- 自己側で保持されているとき → `M_B`
- 操作対象として切り出されたとき → `SILN`

という立ち位置の違いとして扱う。

## T-D — 共有語彙層

全層で共通して参照される記号・基底量・中核概念・相状態・説明用補助表記を定義する独立辞書（DICT）。

```text
T0 / T1
= 仕様と操作

T-D
= それらを何と呼ぶか
```

## Explanation — 成立経路・解説

T0 / T1 に圧縮された構造が、

- なぜ採用されたのか
- どのような問題から立ち上がったのか
- どこで破断しうるのか
- 他の概念とどう接続するのか

を追跡するための説明層。

```text
T0 / T1
= 現在生き残っている構造

Explanation
= その構造が成立した思考経路
```

仕様そのものと、その成立理由を分離することで、Core を小さく保ちながら探索経路を失わないことを目的とする。

↓

↓

↓

## Core Concepts

### `B` — Finite Boundary

観測・認識・記述・操作を行うための有限な選択枠組み。

### `ξ` — Residual Relation

有限境界 `B` による切り出しで回収されない関係。

```text
[B-ξ]

∀B_finite:
  ξ(B) ≠ 0
```

### `M_B` — Consistency Inertia

現在の境界 `B` の内部で自己側に保持され、解釈・予測・応答を形成する整合構造（身体）。

### `SILN`

有限境界 `B` のもとで、RDL 操作の対象としてひとまとまりに切り出された関係構造（食材）。

### `F`

観測された偏りを、現在の `M_B` が解釈した結果。

```text
F = interp(M_B, EFP)
```

### `θ` / `θ_eff`

判定・遷移が立ち上がる境界。局所条件や観測者側構造によって有効境界 `θ_eff` が変動しうる。

### Aporapeiron

有限境界 `B` が未回収関係 `ξ` を伴うため、現在の記述や自己構造を終端的閉包として固定しないという関係的・操作的非閉包条件。

### `[SELF]`

RDL 自身も RDL の操作対象から例外化しない。

```text
M_B(RDL)
   ↓ 対象化
SILN_SELF
   ↓
展開 → 検査と選別 → 再構成
   ↓
M_B'(RDL)
```

## RDL の基本的な問いの立て方

RDL は、いきなり

```text
Xとは何か
```

という問いを終端的な本質探索へ進めない。

まず、

```text
何が X として観測・判定されているか
どの関係がその判定を支えているか
どこまで変化を吸収するか
どこで判定が破断するか
誰の B / M_B でそう見えるか
```

へ展開する。

Examples は、この問いの立て方を具体的に示す。

## Status

RDL は固定された完成理論としてではなく、`[SELF]` に従って RDL 自身も検査・再構成可能な**更新可能な仮設体系**として運用される。

そのため、本リポジトリの内容は、破断条件や新しい有効構造が見つかった場合に変更・更新されうる。

---

## Scope

このリポジトリは **RDL Core** の保持を目的とする。

保持対象は、

- 基盤仮設
- 最低動作仕様
- 基本代謝プロセス
- 共有語彙
- 成立経路・解説
- Coreだけで動かせる基本操作例

である。

個別応用研究、外部理論との大規模接続、専門領域別モデル、過去の前身フレームワーク等は、Core の安定性を保つため原則として別領域へ分離する。
